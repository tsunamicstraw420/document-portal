01 Niche Scanner
Find faceless YouTube niches worth entering right now.



  ●​ Use get_niche_finder_categories and get_niche_finder_tags to
     list every faceless niche available.

  ●​ For each niche, use find_outlier_faceless_channels to find
     channels that (a) launched in the last 3 months, (b) are
     monetized (check_channel_monetization), and (c) are either
     pulling $5K+/month in estimated revenue (get_video_rpm x views)
     OR getting 1M+ views/month.

  ●​ Filter out one-hit wonders. A qualifying channel must show
     consistent views across its last 10+ uploads, not one viral
     spike.

  ●​ For each niche that has at least one qualifying channel, use
     search_niche_finder_channels and get_batch_channel_metrics to
     count large established competitors (50K+ subs, same exact
     format). Kill any niche with 10 or more large competitors in
     the same format.

  ●​ For the surviving niches, use get_niche_overview to pull
     audience profile, RPM range, and dominant format patterns.

OUTPUT

A. Qualifying Niches - Table

  ·​ One row per surviving niche. Columns: niche name, qualifying
     channel count, large competitor count, avg RPM, dominant
     format.


B. Top 5 Niches - Deep Dive

  ·​ Rank by opportunity score. For each: one-sentence definition,
     the 2-3 new channels that qualified and why, the specific
     format they use, audience profile, barrier to entry in one
     sentence.


C. Betting Recommendation
·​ One paragraph: the single niche worth betting on first, and the
  exact format to enter with.
02 Sub-Niche Finder
Zoom into an underserved sub-niche inside one broad niche.




INPUT

Channel URL of any channel already in the broad niche: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and get_niche_overview to define the broad
        niche.

  ●​ Run search_niche_finder_channels on the niche and pull the top
        30 faceless channels.

  ●​ Group those 30 channels by the specific angle they take (e.g.
        inside 'history': ancient civilizations, WW2, medieval,
        American, military tech). List every sub-angle and count
        channels per angle.

  ●​ Run find_outlier_faceless_channels filtered to the same niche.
        Note which sub-angles the recent outliers live in - that's
        where the algorithm is rewarding new entrants right now.

  ●​ Cross-reference: find sub-angles with fewer than 10 established
        channels AND at least 2 recent outliers.

OUTPUT

A. Sub-Niche Map

  ·​ Full list of sub-angles inside the niche with channel counts
        and outlier counts per angle.


B. Top 3 Gaps - Ranked

  ·​ Sub-niche name, one-sentence definition, current channel count,
        outlier evidence (name the channels), audience size estimate,
        why this gap exists (one sentence).


C. 3 Angles Per Gap
·​ For each of the 3 gaps, give 3 specific video angles that would
  work right now.
03 Competitor Breakdown
Deep teardown of the competitive landscape around one channel.




INPUT

Channel URL: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver then get_similar_channels to build a set
        of 15 direct competitors. Filter to faceless only with
        check_faceless_channel.

  ●​ Run get_batch_channel_metrics on all 15 - subs, avg views,
        upload frequency, 90-day growth.

  ●​ For each competitor, run youtube_channel_outliers and pull
        their top 3 outlier videos.

  ●​ Run get_channel_formats on each to classify production style.

  ●​ Run get_video_rpm on the top outlier per channel to estimate
        revenue efficiency.

  ●​ Run get_geography_revenue on the top 5 channels to see where
        the money lives.

OUTPUT

A. Landscape Overview

  ·​ 3-4 sentences: what this competitive landscape looks like right
        now.


B. Competitor Table

  ·​ One row per channel. Columns: name, subs, avg views,
        uploads/month, 90d growth, format, estimated RPM.


C. Top 5 Deep Dive

  ·​ For each top 5 competitor: what they do well, their signature
        format, their top outlier title, and the one thing driving
        their growth.
D. Format Winners

  ·​ The 2-3 formats working across multiple channels (not just
    one).


E. White Space

  ·​ One paragraph on what nobody in this landscape is doing that
    could win.
04 Outlier Radar
Find faceless channels under 50K subs punching way above their weight.




INPUT

Channel URL (used to identify the niche): [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and get_niche_overview to lock the niche.

  ●​ Run find_outlier_faceless_channels filtered to the niche, under
        50K subs, high outlier scores. Take the top 15.

  ●​ Run get_batch_channel_metrics on all 15 - subs, avg views,
        upload frequency, 90d growth.

  ●​ For the top 10, run youtube_channel_outliers and pull their top
        3 breakout videos each.

  ●​ Run get_video_details on the top 5 breakout videos across the
        whole set - CTR, avg view duration, traffic sources.

  ●​ Look for patterns: shared format, hook style, thumbnail
        aesthetic, topic angle, publish cadence.

OUTPUT

A. Top 10 Outlier Channels

  ·​ Table: channel name, subs, avg views, views-to-subs ratio, 90d
        growth, outlier score, one-line description.


B. Top 5 Breakout Videos

  ·​ For each: title, views, channel, one sentence on why it worked.


C. Pattern Report

  ·​ 3-5 patterns that repeat across the outliers. Be specific: 'all
        use bold yellow text in bottom-left of thumbnail' beats 'good
        thumbnails'.


D. Copy Targets
·​ The 2-3 channels worth studying closely before entering this
  niche, and why.
05 Viral Topic Generator
5 ready-to-script video topics based on this channel's proven patterns.




INPUT

Channel URL: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and get_niche_overview. Note niche, avg
        views, typical video length.

  ●​ Run youtube_channel_outliers. Take the top 5 outliers from the
        last 3 months. Record title, views, outlier score.

  ●​ Extract the title formula: the fixed phrase that repeats, the
        variable slot that changes, and any recurring emotional trigger
        words. Write it as a fill-in-the-blank template.

  ●​ Run get_bulk_video_transcripts on the top 3 outliers. Identify
        the shared hook type, content structure, and emotional arc.

  ●​ Run search_videos with the formula to build a taken list -
        every variable slot already covered by this channel or
        competitors.

  ●​ Generate 5 new topics using the formula, filling untaken slots,
        with enough substance for a full video.

OUTPUT

For each of the 5 topics:

  ·​ Title using the exact formula.

  ·​ Why this slot (one sentence - why this specific variable is
        worth filling).

  ·​ Hook direction (one sentence - what the first 30 seconds should
        do).

  ·​ 5-point outline of the video.

  ·​ Competition level (low / medium / high) based on search_videos
        results.
Closing Pick

  ·​ The single topic to create first if it were your channel, and
    why.
06 Title Format Extractor
The title formats winning in this niche, plus 10 new titles that fit the pattern.




INPUT

Channel URL: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and get_niche_overview to lock the niche.

  ●​ Run youtube_channel_outliers on this channel and
        get_similar_channels, then youtube_channel_outliers on the top
        5 similar channels. Combine into a winning-titles set of 30+.

  ●​ Group titles into 3-5 recurring formats (superlative,
        revelation, number-led, question, identity, contradiction,
        etc.). Write the fill-in-the-blank template for each.

  ●​ Count frequency. Identify the #1 and #2 dominant formats.

  ●​ Pull 5 underperforming videos from the same niche
        (search_videos, low views despite being on-topic). Spot the
        losing title patterns.

OUTPUT

A. Format Leaderboard

   ·​ Ranked list of 3-5 formats. Each row: template, frequency in
        winning set, avg views when used, one example title from the
        data.


B. Why They Work

   ·​ Short paragraph on the psychology behind the top 2 formats -
        what emotional button they push.


C. 10 New Titles

   ·​ Five using format #1, five using format #2. All under 60
        characters. Specific, not generic.
D. Avoid List

  ·​ 2-3 title patterns showing up in the losing videos. Don't use
    these.
07 Script Writing Profile
Reusable script DNA extracted from this channel's top outliers.




INPUT

Channel URL: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and youtube_channel_outliers. Take the top
        5 outliers.

  ●​ Run get_bulk_video_transcripts on all 5.

  ●​ For each transcript analyze: hook type (stat / claim / question
        / scene / identity / contradiction), structure (list /
        narrative / investigation / before-after / hybrid), pacing
        (where it speeds up and slows down), voice and tone (formal /
        conversational / provocative, sentence length, reading level),
        evidence mix (data / stories / experts / anecdotes), emotional
        arc (the journey start to end), exit style (cliffhanger / CTA /
        reflection / tease).

  ●​ Find the pattern that repeats across at least 3 of the 5
        videos. That's the channel's DNA.

OUTPUT

A. Voice & Tone

  ·​ 3-4 sentences describing how this channel sounds, plus one
        example sentence that captures it.


B. Hook Template

  ·​ The dominant hook type with a fill-in-the-blank opener - 3-4
        sentences of actual voiceover, not a description.


C. Structure Blueprint

  ·​ The 5-7 section skeleton every video should follow, with what
        happens in each section.
D. Pacing Rules

  ·​ When to go dense, when to breathe, where to place the biggest
    payoff.


E. Evidence Mix

  ·​ Which types of evidence to lean on, with ratios (e.g. 40% data,
    30% story, 30% expert).


F. Exit Formula

  ·​ How every video should end.


G. 3 Things Never To Do

  ·​ Based on what's missing from the winners.
08 Comment Analyzer
Video ideas mined straight from the audience's own comments.




INPUT

Channel URL: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and youtube_channel_outliers. Take the top
        5 outlier videos.

  ●​ For each, run youtube_video_comments sorted by top, limit 100.
        That gives 500 high-signal comments.

  ●​ Classify every comment into one bucket: Requests (explicit
        video asks), Questions (unanswered), Disagreements (pushback or
        nuance), Stories (personal experience), Praise/Noise (ignore).

  ●​ Count frequency. A theme appearing 3+ times across the 5 videos
        is real signal, not an outlier.

OUTPUT

A. Content Demand List

  ·​ Top 10 specific video ideas viewers explicitly asked for. For
        each: what they asked, how many times, proposed title.


B. Unanswered Questions

  ·​ Top 5 questions the existing videos didn't answer but viewers
        keep asking. Each becomes a standalone video with a proposed
        title.


C. Disagreement Angles

  ·​ 3 debates in the comments worth making a response video about.


D. Story Hooks

  ·​ 3 real viewer stories from the comments that could open a
        future video. Quoted, with context.
E. Next 3 Videos

  ·​ The 3 highest-leverage ideas from A/B/C/D, ranked for
    production priority.
09 Viewer Persona Extractor
A psychological profile of who actually watches this channel.




INPUT

Channel URL: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and get_channel_analytics. Log niche, avg
        views, sub count, comment-to-view ratio.

  ●​ Run youtube_channel_outliers. Take top 5 videos.

  ●​ Run youtube_video_comments on all 5, top-sorted, 100 per video.
        500 comments total.

  ●​ Read every comment. Track: vocabulary (10-15 representative
        phrases), knowledge level (beginner / intermediate / advanced /
        mixed), awareness stage (do they know they have the problem?
        are they shopping for solutions?), emotional triggers (what
        gets the most likes - relief, frustration, surprise,
        validation, belonging), stated desires, stated fears, self-ID
        clues (age, job, life stage, situation).

  ●​ Every claim in the persona must be backed by 3+ specific
        comment examples.

OUTPUT

A. Persona Name & Tagline

  ·​ A character name (not a demographic) plus one first-person
        inner-monologue sentence that captures them.


B. Demographic Sketch

  ·​ Age range, life stage, likely job, geography. Each claim marked
        (inferred) or (stated).


C. How They Talk
  ·​ 10-15 real phrases from the comments plus one short paragraph
    written in their voice.


D. What They Know

  ·​ Knowledge level and awareness stage, with 2 quote examples.


E. Top 3 Emotional Triggers

  ·​ Ranked. Each with 2 quote examples and one sentence on how to
    activate it in a hook.


F. Desires vs Fears

  ·​ Two short lists of 5 each, drawn directly from quoted comments.


G. 3 Hook Ideas

  ·​ Three 3-4 sentence hooks written for this persona. Each
    activates a different trigger.
10 Channel Analysis Report
Full diagnostic on a channel with one prioritized next move.




INPUT

Channel URL: [CHANNEL URL]

STEPS

  ●​ Run channel_resolver and get_channel_analytics. Log subs, avg
        views, views-to-subs ratio, 90d growth, upload frequency, top
        geography, RPM estimate.

  ●​ Run youtube_channel_videos for the last 90 days. Split into top
        20% by views and bottom 20%. What's different?

  ●​ Run youtube_channel_outliers. What do the outliers share that
        the flops don't?

  ●​ Run get_short_vs_long_views to see where the audience actually
        is.

  ●​ Run get_geography_revenue for revenue distribution.

  ●​ Run get_similar_channels and pull 10 direct competitors. Run
        get_batch_channel_metrics on all. How does this channel stack
        up?

  ●​ For the top 5 competitors, run youtube_channel_outliers and
        note which formats and topics are working for them that this
        channel isn't touching.

OUTPUT

A. Executive Summary

  ·​ 3-4 sentences: where this channel is today and the single
        biggest question it needs to answer.


B. Health Snapshot

  ·​ Table of key metrics vs competitor median. Green / yellow / red
        flag on each.
C. What's Working

  ·​ Top 3 content patterns driving the outliers. Specific formats,
    topics, angles.


D. What Isn't Working

  ·​ Top 3 patterns in the underperforming videos. What to cut or
    change.


E. Competitive Position

  ·​ One paragraph on where this channel sits in the competitive
    set. Stronger where? Weaker where?


F. Untapped Opportunities

  ·​ 3 things competitors are doing that this channel isn't. Ranked
    by ease of copying.


G. The One Next Move

  ·​ The single highest-leverage action for the next 30 days.
    Specific. One paragraph. Don't hedge.
