Building a Podcast Episode in Riverside
                             from Audio & Video Files Recorded Somewhere Else
                  A complete, current guide to importing media, editing, and exporting a finished episode
        Researched from Riverside's official Help Center (support.riverside.com) and current product pages, 2025




The Workflow at a Glance
You don't have to record inside Riverside to use it. You can bring in audio and video you captured
elsewhere — a Zoom call, a camera, a field recorder, even a YouTube video — and turn it into a polished
episode. The whole journey has six stages:

 Stage                         What happens

 1. Prep your files            Check formats and convert anything Riverside can't read. Decide single-file vs.
                               separate-per-speaker.

 2. Import                     Create > Import. Tell Riverside how many speakers; it builds the project and a free transcript.

 3. Edit the words             Text-based editing: delete, trim, remove filler words and long pauses by editing the transcript.

 4. Polish audio & visuals     Balance voices, clean audio, set the layout, add images / B-roll / music / captions.

 5. Make promo clips           Magic Clips auto-cuts short vertical highlights for social.

 6. Export & publish           Render the full episode (and clips), download, upload to your host, or publish to Spotify.



1. Prepare Your Files Before Importing
This is the stage people skip — and it's where the two biggest headaches live. Get it right and the rest is smooth.

Supported file formats

 Type                 Riverside accepts                                                 Not accepted — convert first

 Video                MP4, WEBM, MPEG (H.264, H.265, VP8, VP9 codecs)                   MOV, AV1, ISO

 Audio                WAV, MP3, OGG (AAC, MPEG, OPUS codecs)                            M4A

 Images               JPG, JPEG, PNG (up to 4096×4096)                                  —

    THE FORMAT TRAP: iPhones and many cameras record .MOV, and most phone voice memos / field recorders save
    .M4A — and neither is on Riverside's supported list. Convert MOV → MP4 and M4A → WAV or MP3 before you
    import (free tools: HandBrake for video, or VLC / an online converter for audio). If an import fails or audio is silent,
    format is the first thing to check.

File size & length limits
•        500 MB maximum per file, and 240 minutes (4 hours) maximum length per file (for the main Create >
         Import path).
•        Video resolution can be up to 4096×4096 (i.e. above 4K is allowed).
•        Each account also has a monthly cap on total upload hours that depends on your plan — see Section
         2.

The single most important decision: one file, or one file per person?
This determines whether you can use Riverside's video layout tools, so decide now:

 If you import…                             What you get

 ONE combined video file (e.g. a            Riverside splits the AUDIO into a separate track per speaker, but there is only
 Zoom recording showing everyone in         ONE video track. You CANNOT change layouts, crop individual people, or switch
 a grid)                                    who's on screen — the picture is locked as filmed.

 SEPARATE video files, one per              Riverside treats each as its own participant track. Now you CAN switch layouts,
 speaker (each person's own camera          crop and reframe each person, and let Riverside cut between speakers
 file)                                      automatically.

 SEPARATE audio files, one per              You get a true multitrack audio edit — balance each voice independently. Ideal
 speaker                                    for audio-only podcasts.

    Takeaway: if your episode is video and you want Riverside to control the on-screen layout, you need the individual
    per-person video files, not one pre-mixed recording. If you only have one combined file, you can still edit and publish it
    — you just keep the layout it came with.

Syncing separate tracks (read this if importing multiple files)
When you upload several files as one session, Riverside layers them to play at the same time — but it does not
auto-align them by sound. Every file must share the same start point. If one person started recording 10 seconds
late, their track will be 10 seconds out of sync forever. Before importing, trim or add silent padding so all tracks
begin at the exact same moment.

3. Importing Your Files
Importing a recording for editing (the main path)
1.          Log in and open the studio (or create one) where the episode should live.
2.          In the upper-right corner, click Create.
3.          Choose Import.
4.          Click Select file (or drag and drop). Pick a file that meets the format and size rules from Section 1, then
            click Open.
5.          From the dropdown, set the number of speakers in the recording. Riverside uses this to build a
            separate audio track per person (you can rename them later in the editor).
6.          Click Upload. Keep the page open until uploading begins; once it's processing you can leave. Riverside
            then transcodes the file and generates a free transcript.
    To cancel a running upload, hover the file's thumbnail and click the X.

Importing multiple files as one multitrack session
Use this when you have a separate file per speaker and want them on one synced timeline:

1.          Start the same Create > Import flow but select all the files together.
2.          You'll see a checkbox: “These are different participants from the same recording session.”
3.          Check it to layer the files so they play simultaneously (one track per person) — this is true multitrack.
            Leave it unchecked to place files one-after-another in sequence (for stitching unrelated segments).
4.          Confirm each track shares the same start point (see the syncing note in Section 1), then upload.

Importing from a YouTube link (beta)
•        In Create > Import, paste a YouTube URL, set the number of speakers, and upload.
•        Limits: up to 3 hours; the video comes in at low resolution (around 640×360); the video must be public or
         unlisted.
•        Not supported: private/members-only videos, Shorts, active livestreams, or region-restricted videos.
•        This feature is rolling out gradually, so it may not appear in every account yet.
    No native Zoom, Dropbox, or Google Drive importer is confirmed. For those, download the file to your computer first, then
    import it normally.

4. Editing the Episode (Text-Based Editing)
Riverside edits like a word processor: you edit the transcript, and the matching audio and video are cut to follow.
Open your imported recording and click Edit (or Go to editor). The transcript sits on the left; the video preview
and timeline fill the rest.

Core moves: highlight text, then choose from the toolbar

 Action                     How it works

 Trim / delete              Highlight the words and press Delete (or the trash button). The matching footage is removed too.
                            Editing is non-destructive — nothing is gone for good.

 Restore a deletion         Deleted text stays visible, grayed out with “…”. Click it and choose Restore (shortcut: R) to bring
                            the words and footage back.

 Mute                       Silences a section WITHOUT cutting the picture — useful so an on-camera speaker doesn't
                            visually “jump.”

 Correct                    Fix a mis-transcribed word (e.g. a name). Keeps captions accurate.

 Keep only this             Deletes everything except the highlighted selection — fast way to isolate one segment.

 Add                        Insert text, an image, B-roll/video, or music at that point in the transcript (covered in Section 6).

 Split (S)                  Cuts the timeline at the playhead so you can move or treat pieces separately.


AI cleanup tools (the “AI Producer” / Magic tools)
Open the AI tools from the editor toolbar. These do in one click what used to take hours:

•        Remove filler words — strips “um,” “uh,” “so,” etc. across the whole episode. Three modes: Cut (fully
         removes), Mute (silences in place), and Smart (a natural-sounding mix). Note: only works on recordings
         made or uploaded after May 2024.
•        Remove pauses — drag a slider to set how much silence to keep; anything longer is cut. Tighten it for a
         punchy solo episode, loosen it to keep a natural conversational feel. Optional: also apply to screen-shares
         and media.
•        Find Fluff — AI flags off-topic chatter, repeats, mistakes, and technical hiccups to remove (this is the real
         name of the “clean it up for me” feature).
•        Smart Layouts / Smart Scenes — AI automatically switches camera angles/layouts for a dynamic edit;
         apply first, then refine by hand.
    Always watch the result through before exporting. AI cleanup is good but not perfect — it occasionally clips a real word
    or cuts a beat you wanted.


5. Polishing the Audio
•        Per-speaker volume — in the right-hand Tracks panel, expand a participant and adjust their level. This
         applies across the whole episode, so you can lift a quiet guest or tame a loud one. (This is exactly why
         importing separate per-speaker tracks is worth it.)
•        Magic Audio (Pro & Business) — one toggle that removes background noise and echo and auto-balances
         tone for a studio sound. You can blend the cleaned audio back with the original so it doesn't sound
         over-processed.
•        Remove background noise — a lighter, standalone noise reducer if you don't want full Magic Audio.
•        Normalize audio levels — applied at export (see Section 8). Evens out loud-vs-quiet speakers to
         broadcast loudness (Riverside targets the −23 LUFS standard) so listeners aren't reaching for the volume.
    Test before trusting: AI audio cleanup can over-correct on already-decent recordings. If your source sounds fine, a light
    touch (or just Normalize) often beats heavy processing.


6. Adding Images, B-roll, Music & Text
The right-hand panel has tabs for Images, Videos, Music, and Text. For each you can pull from Riverside's
built-in royalty-free library or upload your own, then drag it onto the canvas and set its size, position, and
on-screen duration.

Images & B-roll (the cutaway visuals)
•        Two ways to place it: highlight a phrase in the transcript and choose Add > image/video to lay a visual
         over that exact moment, OR drag a clip onto the timeline manually.
•        Built-in stock library — searchable royalty-free images and video clips, so you often don't need a
         separate Storyblocks/Envato subscription. Riverside also suggests B-roll based on what's being said in the
         transcript.
•        Upload your own — PNG, JPG, JPEG images (up to 4096×4096) and MP4/WEBM/MPEG video, up to
         500 MB per file. Tip: if you want an uploaded intro/outro to be text-editable and transcribed, bring it in
         through Create > Import rather than the plain Uploads area.
•        Logos — add a logo overlay, or set it once in the Brand Kit (position and opacity) so it appears on every
         export.

Music & sound
•        Music tab — choose a royalty-free track (tagged by mood/genre) or upload your own intro/outro music. It
         lands on a dedicated music track below the dialogue.
•        Volume & fades — select a music clip and open Volume & effects for a level slider and fade-in/out (up to
         5 seconds each). A common starting point is roughly 40% volume under speech.
•        Media Board (soundboard) — a free library of sound effects/stings, mainly used live while recording.

Text & lower thirds
The Text tab adds titles, lower-thirds (the name/title bar across the bottom of the frame), and call-to-action
overlays like “Subscribe.” Presets get you started; brand-kit styles keep them consistent.


7. Layout & Captions
Layout (only fully available with separate video tracks)
•        Full screen — one speaker fills the frame. Great for focus and for solo segments.
•        Grid — everyone in equal panels; also the view you use to crop/reposition each person.
•        Picture-in-picture — one speaker large with others inset.
•        Speaker / split screen — the active talker is larger, others alongside.
•        Smart Layouts — Riverside auto-switches between these through the episode to reduce visual
         monotony.
•        Fill vs Fit — Fill zooms each video to fill its frame (no black bars); Fit shows the whole frame (may add
         bars). Crop and reframe each speaker individually in Grid view.

Captions / subtitles
•        Auto-generate captions from the transcript (100+ languages).
•        Click the caption text on the canvas to change font, size, colors, capitalization, alignment, and animation
         — including the popular highlight-as-you-speak (“karaoke”) style. Drag to reposition; you can place
         captions differently per scene.
•        Save your styling as a caption preset (or set it in the Brand Kit) so every future video matches without
         redoing it.


8. Auto-Generating Promo Clips (Magic Clips)
Magic Clips scans your long episode (imported files included) and produces short, social-ready highlights —
vertical 9:16 by default, with animated captions baked in and, for audio-only, a background image.

•        Expect roughly 2 clips per 5 minutes of conversation, each about 30–90 seconds.
•        Steer it: set clip length, pick a focus speaker, or enter keywords/topics to target a remembered moment.
         Auto mode gives a first set you can refine.
•        Re-run it (Pro & Business can generate extra clips beyond the auto set) — a second pass often surfaces
         different moments. Volume of options is the point.
•        Switch a clip to 16:9 if you want a landscape highlight or a hook for the top of the episode.
    Don't only make short clips — a 5- or 10-minute segment of a long episode, republished on its own, can outperform the
    full show. Mix short, medium, and long clips.


9. Exporting & Publishing
Click Export (top-right). The Export Options panel is where final quality is decided:

 Setting                        Guidance

 Resolution                     Up to 4K/2160p (Pro+), or 1080p / 720p. Audio-only available as MP3 or WAV.

 Remove watermark               Turn on (paid plans) to drop Riverside's branding.

 Normalize audio levels         Recommended — evens out speaker loudness. (Riverside also auto-applies broadcast
                                normalization to every export.)

 Remove background noise        Optional; can over-process. Test before relying on it.

 Audio format                   WAV = highest quality master; MP3 = smaller file for hosts.

Exports render on Riverside's servers; when finished, a download icon appears on the file. Download it, then
upload to your podcast host or YouTube. A useful habit: export a couple of versions (e.g. normalized vs not) and
put the setting in the filename to compare.

Publishing options
•        Direct to Spotify — click the Spotify button, connect your Spotify for Creators (Anchor) account, add
         title/description, and publish. Audio then distributes to the platforms linked to that account.
•      Hand off to a pro editor — Business plans can export an XML timeline into Premiere Pro, Final Cut Pro,
       or DaVinci Resolve. Important: only your cuts/trims, chapters, and comments carry over — AI effects,
       media inserts, and overlays do NOT, so add those in the destination app.
•      Anywhere else — just download the MP4/MP3/WAV and upload it to YouTube, Apple Podcasts, or any
       host manually.


Start-to-Finish Checklist
Your repeatable recipe for turning outside recordings into a published episode:

1.       Gather your files. Convert any MOV → MP4 and M4A → WAV/MP3. Decide: separate per-speaker files
         (for layout control) or one combined file.
2.       If using multiple files, make sure they all start at the same instant (trim or pad).
3.       Create > Import. Set the number of speakers; for multi-file, check “same recording session.” Upload and
         let it transcribe.
4.       In the editor, do the text pass: delete dead weight, run Remove filler words and Remove pauses, use
         Find Fluff, then restore anything it over-cut.
5.       Balance each speaker's volume; apply Magic Audio or noise removal only if needed.
6.       Set the layout (separate video tracks only) and add captions; style them once and save a preset.
7.       Add intro/outro, music (with fades), B-roll, lower thirds, and your logo.
8.       Generate Magic Clips for promo; tweak the best ones.
9.       Export the full episode (normalize on, watermark off), download, and publish to your host or Spotify.
         Repeat export for each clip.
