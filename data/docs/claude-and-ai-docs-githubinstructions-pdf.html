GitHub Setup Instructions
                                    Polymarket Latency Arbitrage Bot




1 · Prerequisites
Before starting, make sure you have the following:

•   Git installed — check by running git --version in Terminal. If not installed:
    https://git-scm.com/download/mac

•   GitHub account — free at https://github.com

•   GitHub CLI (optional but recommended) — https://cli.github.com — lets you create repos from the
    terminal



2 · Create a New Repository on GitHub
Go to GitHub and create the remote repo before connecting your local files:

•   Sign in at https://github.com

•   Click the ■ icon (top-right) → New repository

•   Fill in the form:


    Field                              Recommended value

    Repository name                    Polymarket-Arbitrage-Bot

    Description                        Latency arb bot for Polymarket BTC/ETH contracts

    Visibility                         Private — keeps your strategy confidential

    Initialize with README             Leave UNCHECKED (you already have local files)

    .gitignore                         Leave as None (repo already has one)

Click Create repository. GitHub will show a page with setup commands — copy your repo URL (looks like:
https://github.com/YOUR_NAME/Polymarket-Arbitrage-Bot.git)


3 · Initialise Your Local Repository
Open Terminal, navigate to the bot folder, and run these commands one at a time:
cd /Users/rubys/Desktop/py-clob-client-main/Polymarket-Arbitrage-Bot

git init

git add bot.py config.py strategy.py market_scanner.py order_manager.py

  live state.

git commit -m "Initial commit — Polymarket latency arb bot"



4 · Connect to GitHub and Push
Replace YOUR_USERNAME with your actual GitHub username:

git remote add origin https://github.com/YOUR_USERNAME/Polymarket-Arbitrage-Bot.git

git branch -M main

git push -u origin main

  GitHub will prompt for your username and password. For the password, use a Personal Access Token (not
  your account password). Create one at: https://github.com/settings/tokens → Generate new token (classic) →
  check repo scope → copy the token.


5 · Pushing Future Updates
Every time you make changes and want to save them to GitHub:

cd /Users/rubys/Desktop/py-clob-client-main/Polymarket-Arbitrage-Bot

git add bot.py config.py strategy.py

git commit -m "Brief description of what changed"

git push

  Only add the specific files you changed. Avoid git add . or git add -A as these can accidentally
  include secrets.

7 · What the .gitignore Protects
The bot's .gitignore is already configured to exclude:

•    .env — your private keys and API credentials

•    positions.json / state.json — live trading state

•    trades.db — trade history database

•    bot.log — runtime logs

•    venv/ — Python virtual environment (large, machine-specific)

•    __pycache__/ — compiled Python bytecode

•    .DS_Store — macOS folder metadata

    These files are automatically excluded — you never need to worry about accidentally committing your private
    key.
