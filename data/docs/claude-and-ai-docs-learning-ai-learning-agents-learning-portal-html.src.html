The one idea that makes everything click

An agent is just a model + instructions + tools + memory + a loop. It reads a goal, picks a next step, uses a tool, looks at the result, and repeats until the job is done. Every framework and platform in this portal is a variation on that single loop. Hold onto it.

🤖 Agent vs. chatbot

A chatbot answers. A workflow follows fixed steps. An agent decides its own steps toward a goal and uses tools to act.

🧭 How to use this portal

Work the Learning Path top to bottom. Do the BUILD item in each phase — don't just read. Tick lessons off as you finish them.

🗓️ Pace

~6 weeks at 3–5 hrs/week, or faster if you go full-time. One phase per week is a comfortable rhythm.

Project → Agent worksheet (copy per project)

  1. The job — in one sentence, what should this agent accomplish?
  2. Trigger — what starts it? (a schedule, a new email, you asking, a file appearing)
  3. Steps & tools — what does it do, and what apps/tools does each step need?
  4. Inputs & memory — what does it need up front, and what should it remember between runs?
  5. Human-in-the-loop — which steps must you approve first?
  6. Build lane — no-code, Claude/Cowork, or commission a coded build? Why?
  7. Weekend v1 — the smallest version you could get working fast.
  8. Grown-up version — what it becomes if it proves useful.
  9. How you'll test it — 5 real examples and what "good" looks like.

One-paragraph spec to hand a builder or Claude: "Build an agent that [job]. It triggers when [trigger]. It should [step 1], [step 2], [step 3], using [tools]. Before [risky step], it must ask me to approve. It remembers [memory]. Build v1 in [lane]. I'll test it on [examples] and call it working if [criteria]."

    Agents for the podcast

    Concrete agents mapped to your weekly production pipeline (research → script → record → edit → publish). Golden rule for this project: an agent should wrap the working scripts and skills you already have, not reinvent them.

    🔎 Episode research & SEO title agent MON

    Scans reality-TV news for the shows you cover, proposes episode topics and SEO titles, and drafts the Notion episode card.

    Lane: Claude/Cowork + web search + Notion connector

    ✍️ Script + teleprompter agent TUE

    Drafts the production script in Ruby's voice, strips it to the clean teleprompter version, and cross-checks every cast member against the manifest.

    Lane: Claude Skill (you already have reality-recap-script) wrapped as an agent

    📝 Show notes & chapters agent THU

    Turns the YouTube auto-transcript into show notes, description, and timestamped chapters — writes to the Content Calendar & Show Notes Library.

    Lane: Claude/Cowork + Notion

    ✂️ Shorts picker agent THU

    Reads the final master's transcript, nominates the best 30–60s moments by timecode, and hands windows to your make_shorts.py.

    Lane: Agent proposes → existing script cuts (human confirms picks)

    🎬 Caption / karaoke build agent

    Wraps your locked caption pipeline (own word-level transcript → karaoke burn) so a run is one instruction, with the dense timing check built in.

    Lane: Agent orchestrates your existing caption-capable render scripts

    📣 Publishing & social agent FRI

    On publish day, drafts the Facebook post and email newsletter, and preps the RSS/Zap checklist for you to fire.

    Lane: Claude/Cowork drafts → you approve & publish

    ✅ QA / verification agent

    Before "done," checks cast roll-call count vs. the manifest, runtime vs. the 15:00 cap, and caption alignment — mirroring your self-check block.

    Lane: Claude subagent dedicated to verification

    🔁 Repurposing agent

    Spins each episode into a blog post / newsletter section for search and reach, from the same transcript.

    Lane: Claude/Cowork

    Where to start: the show notes & chapters agent or the QA / verification agent — both are low-risk, save real time every episode, and build on transcripts/scripts you already produce.

    Agents for small-business operations

    In 2026 most small businesses don't automate their craft — they automate the front office: answering every call, booking, follow-up, reminders, and paperwork. Below are the highest-value agent patterns per industry, with the kind of results being reported. A voice/receptionist agent is the common first win almost everywhere.

    🦷 Dental / medical office

    Pain: Front desk drowns in scheduling, reminders, intake, insurance checks.

    Agent does: 24/7 scheduling & confirmations, recall/reactivation outreach, insurance verification, intake, payment posting.

    Tools: Patientdesk.ai, Weave, Dental Intelligence, Vapi voice; PMS: Dentrix / Open Dental / Eaglesoft.

    Reported: ~32% fewer no-shows, 45% faster intake

    🔨 Construction / remodeling

    Pain: Missed calls become lost jobs; estimating & follow-up eat evenings.

    Agent does: Answers every call, schedules estimates, follows up on quotes, organizes project data, updates the CRM.

    Tools: Procore AI, Buildertrend, Handoff, GoHighLevel, Vapi.

    Reported: 40–65% more lead capture, 30–45% better estimate conversion

    🔧 Home services (HVAC / plumbing / electrical)

    Pain: Missed calls cost $45k–$125k/yr; emergencies go to voicemail.

    Agent does: 24/7 answering, detects emergency keywords & dispatches, books jobs, runs re-engagement drips.

    Tools: Voice agents (Vapi/PolyAI-style), ServiceTitan, GoHighLevel.

    Reported: pays for itself in ~4–6 weeks at $30k+/mo

    🍽️ Restaurant

    Pain: Nobody free to answer the phone during service; missed reservations.

    Agent does: Takes reservations & phone orders, answers hours/menu questions, handles simple complaints, syncs to POS.

    Tools: PolyAI, Bookline, Voiceflow; POS & booking integrations.

    Reported: ~74% of diners comfortable with AI booking

    💇 Salon / spa

    Pain: Stylists can't book while hands are busy; slow off-peak hours.

    Agent does: 24/7 voice booking, answers service/pricing questions, logs to CRM, suggests off-peak discounts to fill gaps.

    Tools: AI receptionist (CloudTalk-style), AgentZap, salon booking suites.

    Best lane: hosted vertical product or no-code voice agent

    ⚖️ Law firm

    Pain: Billable hours lost to intake, drafting, and document review.

    Agent does: Client intake & qualification, first-draft memos/letters in the firm's voice, document summarization, deadline tracking.

    Tools: Custom agents on firm templates/playbooks; Claude/GPT + doc tools.

    Best lane: Claude Project trained on firm templates (careful with confidentiality)

    🏠 Real estate / property mgmt

    Pain: Lead response speed, listing paperwork, tenant maintenance tickets.

    Agent does: Instant lead reply & qualification, listing/description drafts, opens maintenance tickets, dispatches vendors, messages tenants.

    Tools: CRM automation + voice/chat agents; real-estate AI suites.

    Best lane: no-code (n8n/GoHighLevel) + voice agent

    🚗 Auto repair

    Pain: Phone rings during work; quotes & status updates slip.

    Agent does: Books appointments, triages urgent vs. routine, sends status updates & service reminders.

    Tools: Ciela-style shop agents, voice answering, shop CRM.

    Best lane: hosted vertical product or no-code voice agent

    🛍️ Retail / e-commerce shop

    Pain: Repetitive support tickets, order status, inventory questions.

    Agent does: Answers product/order/returns questions across chat/email/DM, triages tickets, flags inventory gaps.

    Tools: Support agents (Botpress/Fini/LiveChatAI-style), Dify for product Q&A.

    Best lane: no-code chat agent (Dify) + support platform

    📚 Bookkeeping / accounting

    Pain: Invoice chasing, receipt sorting, reconciliation, reminders.

    Agent does: Sends invoice follow-ups, categorizes transactions, drafts monthly reports, flags anomalies.

    Tools: n8n/Zapier + accounting app connectors.

    Best lane: no-code workflow agent (keep a human on the money moves)

    🏋️ Fitness studio / gym

    Pain: Class booking, membership questions, win-back of lapsed members.

    Agent does: Books classes, answers membership/pricing questions, runs re-engagement drips, collects reviews.

    Tools: Voice/chat agent + booking software + CRM.

    Best lane: no-code + hosted booking

    💡 The universal starter agent

    Whatever the industry, the first agent to build is almost always the 24/7 receptionist: answer every call/text/DM, book or route, and follow up. It's the fastest ROI and the easiest to scope.

    Selective wins: invoice follow-ups, reminders, lead qualification, review requests, reporting.

    Reality check from the research: the businesses that win aren't automating everything — they're selective, they test carefully, and they keep a human wherever judgment, empathy, or relationships matter. Reported median payback across functions is ~5 months.

    Glossary

    Agent — an AI system that pursues a goal by deciding its own steps and using tools, looping until done.

    Tool use / function calling — the model's ability to call external actions (search, send email, run code).

    ReAct — interleaving reasoning ("think") and acting ("do") step by step.

    RAG — Retrieval-Augmented Generation; the agent looks up relevant documents and uses them to answer.

    MCP (Model Context Protocol) — the open standard that lets agents plug into tools and data — "USB-C for AI."

    Skill — a reusable capability package an agent auto-uses when relevant.

    Subagent — a specialist agent a main agent delegates a bounded task to, with its own context.

    Orchestration — coordinating multiple steps or agents toward one goal.

    Memory — short-term (the current context window) or long-term (stored, retrievable facts/history).

    Evals — tests that measure whether an agent produces good results, run on real examples.

    Guardrails — rules/permissions that limit what an agent can do and require human approval for risky actions.

    Human-in-the-loop — a person reviews or approves certain agent steps.

    Context window — how much text the model can consider at once.

    Token — the unit of text models process and are billed on; more tokens = more cost.
