Put your learning portal online (GitHub Pages)

This gets your portal onto a real web address you can open from your phone, laptop, anywhere — for free, permanently, no coding. It's all done in the browser (no command line). Takes about 10 minutes the first time.

The file you'll upload: index.html (in this same folder). It's the exact same portal — GitHub just requires the name index.html to show it as a webpage.

Step 1 — Make a free GitHub account (skip if you have one)

  1. Go to https://github.com and click Sign up.
  2. Pick a username you like — it becomes part of your web address (e.g. username eddiebarna → your site will be https://eddiebarna.github.io/...).
  3. Verify your email.

Step 2 — Create a repository (a project folder)

  1. Click the + in the top-right → New repository.
  2. Repository name: type agents-portal (lowercase, no spaces).
  3. Set it to Public (required for free GitHub Pages).
  4. Leave everything else as-is and click Create repository.

Step 3 — Upload the portal file

  1. On the new repository page, click the link "uploading an existing file" (it's in the "Quick setup" text). If you don't see it, click Add file → Upload files.
  2. In Finder, open this folder and drag index.html onto the upload area (or click "choose your files" and select it).
  3. Scroll down and click the green Commit changes button.

Step 4 — Turn on GitHub Pages

  1. In the repository, click Settings (top menu).
  2. In the left sidebar, click Pages.
  3. Under Build and deployment → Source, choose Deploy from a branch.
  4. Under Branch, pick main and folder / (root), then click Save.
  5. Wait about 1–2 minutes. Refresh the page — a banner appears:

"Your site is live at https://YOURUSERNAME.github.io/agents-portal/"

That link is your portal. Bookmark it on your phone and laptop. It works on any device and is mobile-friendly.

Keeping your progress across devices

Your checkmarks are saved on each device separately. To move them:

  1. On the device where you've been ticking lessons, click Export progress (top of the portal). It copies a short code.
  2. On your other device, open the same portal link, click Import progress, paste the code, and press Apply. Done — both devices now match.

Do this any time you want to sync (it's manual, not automatic).

Updating the portal later

When you (or I) improve the portal, you just replace the file:

  1. Go to your agents-portal repository → click index.html → click the pencil (Edit) icon, or use Add file → Upload files and drop the new index.html over it.
  2. Click Commit changes. Your live site updates within a minute — same web address.

Notes

  • Public but private-ish: the page is technically public, but nobody will find it unless you share the exact link. It's just a personal learning portal, so that's fine.
  • Free forever: GitHub Pages has no cost for this.
  • If the link 404s at first: wait another minute and refresh — Pages can take a moment to publish the first time.
