Overview

This lesson covers Wan 2.2 Replace (accessed on PromptEdit.com), used to swap the character in an existing video clip for a different one while preserving the original scene, motion, and camera. You provide the source video and a reference for the new character, and the tool re-renders the clip with the character replaced.

Practical notes from the instructor's Q&A (comments)

  • A student reported that trying to replace a human with a dog didn't work — it turned into a different human. This suggests the tool is tuned for human/character-to-character swaps rather than swapping a person for an animal.
  • Students also asked about swapping multiple characters in the same clip and changing the voice at the same time (voice changes are handled separately — see the AI Voice Swap lesson).

Where it fits

It pairs naturally with the other clip-editing tools in this module (Runway Aleph for effects/angles, Wan 2.2 for background replacement, Kling o1 Edit for prompt-based clip edits) — all ways to modify footage you've already generated or filmed rather than generating from scratch.
