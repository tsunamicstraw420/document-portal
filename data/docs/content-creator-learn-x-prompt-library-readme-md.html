X Prompt Library — @TechieBySA

A browsable, reusable library of AI-animation prompts reverse-engineered from the X account @TechieBySA (bio: "AI tools, prompts & wild ideas"). Built so we can study his method and generate clips on par with his work.

Scraped: 2026-09-03 · Window: Jun 1 – Sep 3, 2026 (the full 3 months — 228 prompt-set threads plus standalone prompt posts = 297 browsable cards, 623 posts total).

His method in one line

Two-stage pipeline every time: GPT Image 2 "character bible sheet" (locks the look) → Seedance 2.0 / 2.5 (animates it through an 8-beat, timecoded action arc). Full breakdown in STYLE_ANALYSIS.md.

Notes / honesty

  • Clips are links + poster frames, not video files. X streams video, so the library stores

each clip's poster still and a link to watch it on X (the agreed approach). The full prompts and character-sheet images are captured completely.

  • Prompts are the full untruncated text — pulled from X's data layer, including his

long-form "note" posts, so nothing is cut off.
