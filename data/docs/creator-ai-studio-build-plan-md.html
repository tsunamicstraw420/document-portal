ShowKit — Build Plan

The single source of truth for what to build and in what order. Companion research: docs/niche-and-competitors.md (why/who) and docs/unit-economics.md (pricing/margin).

The bet (from research)

Do not sell "access to AI models" — that's a commodity (Pollo AI, davinci.ai already do it and compete on price to the bottom). Sell outcomes for a niche you own:

"Turn one podcast episode into a week of on-brand thumbnails, Shorts, intros, audiograms, and quote cards — one credit wallet, all the best models, none of the busywork."

Moat = one-click creator formats + your already-licensed template/sound library wired in as intro/title/audio layers + a persistent brand kit + your existing audience as warm distribution. A thin reseller cannot copy those.

Architecture (see docs/architecture.md for detail)

  • Frontend: Next.js (App Router, TS, Tailwind).
  • Auth + DB + Storage: Supabase (Postgres, Auth, Storage/R2 for outputs).
  • Payments: Stripe — subscriptions (3 tiers) + one-time credit packs + webhooks.
  • Model access (server-side): OpenRouter (unified image+text), fal.ai (fast image/video),

Replicate (breadth). Adapters behind one internal interface.

  • Core: the credit ledger + the model catalog + the generation pipeline.

Data model (see db/schema.sql)

users · credit_wallets (balance) · credit_transactions (append-only audit ledger: signup grant, top-up, subscription refill, reservation, settle, release, refund) · generations (job record: model, prompt, status, cost, output URL) · subscriptions (Stripe state) · model catalog lives in lib/models.ts.

Economics baseline (from docs/unit-economics.md — tune with the calculator)

  • 1 credit = $0.02 list (pay-as-you-go) ≈ 4× wholesale ≈ ~75% gross margin pre-Stripe.

Subscription credits are bundled cheaper (~$0.013–0.016 effective) — margin protected by breakage + tier design.

  • Model credit costs: cheap image (Flux Schnell / SDXL) = 1 credit; premium video

(e.g. Veo 3.1 5s w/ audio) up to ~400 credits. Full table in the doc.

  • Tiers: $9 Starter (550 cr) · $19 Creator (1,300 cr) · $49 Studio (3,800 cr) + top-up

packs + a small free trial. Modeled net ≈ $11K/mo at 1,000 paying users (before salary, CAC, refunds).

Phases

Phase 0 — Setup. Init Next.js + TS + Tailwind over this scaffold. Create Supabase project (auth on), Stripe test account, and an OpenRouter key. Fill .env.local from .env.example.

Phase 1 — Core loop (thin vertical slice). Sign in → grant free-trial credits → generate one image model (Flux via OpenRouter or fal) through app/api/generate/route.ts using the ledger (reserve → call → settle, in a transaction, with an audit row) → display + store the result. This proves the entire spine. Do not move on until a credit is charged correctly.

Phase 2 — Monetization. Stripe: 3 subscription tiers + top-up credit packs + the idempotent webhook that refills the ledger on invoice.paid / checkout.session.completed. Customer billing portal. Trial → paid upgrade path.

Phase 3 — Model catalog + breadth. Flesh out lib/models.ts with the wholesale→credit map, provider adapters (OpenRouter / fal / Replicate), more image models + basic video. Add a job queue + provider webhooks for long-running video.

Phase 4 — Creator formats (the moat). One-click formats: episode → thumbnail / Short / intro / audiogram / quote card. Wire in the existing template + sound library (../Content_Creator_Learn/…) as layers. Per-user brand kit (fonts, colors, logo).

Phase 5 — Compliance + launch. Prompt/output moderation, NCII report + 48-hr takedown flow, ToS / Privacy / Refund policy, rate limits + Stripe Radar, basic analytics + admin. Deploy (Vercel + Supabase). Private beta to the existing audience, then open.

Locked decisions (from research — don't relitigate without cause)

  • Provider keys server-side only (fal ToS); build where reselling-via-your-app is permitted

(Replicate/OpenRouter); re-check each provider's ToS before adding it.

  • Moderation + NCII takedown ships before launch.
  • Credits are integers; ledger is append-only + transactional; webhooks idempotent.
  • Model catalog is data-driven so a wholesale price change is a config edit, not a refactor.

Open decisions for Eddie (pick before/while building)

  • Name: ShowKit (lead) · ReelForge · ClipSmith · ShowRunner.
  • Wedge: podcasters/short-form (lead) vs faceless UGC ad creators vs newsletter/course.
  • Tier prices / allowances: start from the calculator, then A/B.
