GTO_Holdem — Project Rules

Read the house rules in ../CLAUDE.md first. This file adds the rules for this project only.

What this project is

Eddie's own NLHE GTO study and drill system. It covers preflop charts, push/fold, ICM, postflop solutions and a drill trainer, across four formats: 6-max cash, MTTs with ICM, Spin & Go, and live full-ring.

  • Off-table study only. Never build real-time assistance.
  • It is built to become a paid web app.

The plan comes in two copies. Change both together.

  • IMPLEMENTATION_PLAN.md is Claude's working copy.
  • IMPLEMENTATION_PLAN.html is Eddie's copy. After every change, republish it from that same path so it stays at https://claude.ai/artifact/XjLVMo1zSYrYZBVEHL7eMc.

License firewall (never break it)

  • AGPL code runs only offline, on our own machines. That covers b-inary postflop-solver, wasm-postflop, desktop-postflop and TexasSolver.
  • It never goes on the web server.
  • It never ships in a browser bundle.
  • It is never linked into the app.
  • Only its output files cross into the product.
  • App dependencies are MIT, Apache, BSD, ISC, or our own code. Check every new dependency's license before adding it. Never add GPL or AGPL code, or code with no license at all.
  • Never import, scrape or copy third-party poker content into anything that ships. That covers GTO Wizard content (free tier included), PioSolver output, and charts from training sites. Comparing by eye to validate our own results is fine.
  • Preflop charts are built in-house, never licensed. Eddie decided this on 2026-10-06.
  • Our own postflop engine (Phase 7) is written clean-room from the published papers, such as DCFR. Never copy from AGPL source.

Working rules

  • Every phase ends with its "Done when" gate from the plan. Report the actual numbers.
  • Label every number as Verified, Checked or Estimate.
  • Paid compute:
  • Run a test batch first: about 20 solves on one rented machine, under $1.
  • Only then start a full run.
  • Rented machines must shut themselves down when the job list is empty.
  • Budget is Lean: about $400 of compute in total. That covers the 6-max cash starter, the 8-max MTT starter, Spin on 184 flops, and one 100bb preflop run. Ask Eddie before going over it.
  • The MTT and Spin preflop runs are not inside the $400. Measure each one with a test batch, then get Eddie's approval.
  • Table sizes (decided 2026-10-06):
  • Cash: 6-max, 7-handed and 9-handed.
  • MTTs: 7-, 8- and 9-handed.
  • 6-max cash and 8-max MTTs come first. 7- and 9-handed follow once 6-max preflop is proven, with their own budget approval.
  • Each table size is a separate preflop solve. Postflop stays heads-up.
  • Pace is the fast track: daily sessions, with three tracks run in parallel.
  • Track A, short stacks to the first paid product: Phase 1 → Phase 2 → Launch 1.
  • Track B, postflop and cash charts: Phase 3 → Phase 4 → Phase 5 → Phase 6.
  • Track C, our own engine: Phase 7.
  • Tooling on this Mac (2019 Intel, macOS 26):
  • Rust lives in ~/.cargo/bin, which is not on PATH. Call ~/.cargo/bin/cargo directly. It was installed with the official rustup installer, after its checksum was verified against rust-lang.org.
  • Don't use Homebrew for build tools here. It has no ready-made packages for this Intel/macOS combination, so it compiles things like cmake from source for hours.
  • pnpm 12 reads its settings from web/pnpm-workspace.yaml, not .npmrc. The virtualStoreDir setting there keeps packages out of iCloud.
  • The postflop-solver copy needs bincode and bincode_derive pinned to 2.0.0-rc.3 in its Cargo.lock. It also has three one-line fixes in action_tree.rs for Rust 1.99.
  • The trainer for Eddie: https://claude.ai/artifact/6CFTAGSMfbhe8z293KCz5j. It's a private page that opens on any device. The Drill, Charts and ICM screens work there; the Postflop screen needs the local service on the Mac.
  • To update it:
  1. Build with pnpm --dir web exec vite build --base ./ --outDir ~/GTO_Holdem_work/build/artifact-dist.
  2. In the session scratchpad, assemble a page: <title>, the Google Fonts link, the built CSS inlined in <style>, <div id="root">, and <script type="module" src="assets/app.js">.
  3. Publish it with url = the link above. Pass files mapping assets/app.js → the built JS and data/pushfold_hu.json → the chart data.
  • The localhost dev preview (.claude/launch.json "drill-app") is for development only. The Claude app stops it on its own.
  • Local postflop service (AGPL zone, this Mac only):
  • Start it: cd ~/GTO_Holdem_work/agpl-solvers/postflop-solver && ./target/release/examples/gto_spot_server. It serves 127.0.0.1:8777, and the app's Postflop screen talks to it.
  • Stop it when you're done (pkill -f gto_spot_server). A solved flop holds about 5 GB.
  • TexasSolver (cross-checks only):
  • Build with make -C build-mac in ~/GTO_Holdem_work/agpl-solvers/TexasSolver, on the local branch gto-holdem-local. Don't push it.
  • It needs no OpenMP or CMake; its two OpenMP loops were swapped for C++ threads.
  • It uses about 1.4× postflop-solver's memory and is about 4.5× slower.
  • Real memory limit on this Mac: with Eddie's apps open, only solves up to about 5 GB run cleanly. Over that:
  • use "compress": true (16-bit, half the memory);
  • or run while the Mac is idle;
  • or rent a machine.

A 7.65 GB solve swapped to a halt on 2026-10-06.

  • Measured flop solve time here: 2 flop sizes + all-in, 100bb-deep single-raised pot (pot 55, stack 975), 8 threads. It takes about 11 minutes and 4.8 GB per flop.
  • License exception on record: lightningcss (MPL-2.0) is Vite's build-time CSS tool. It doesn't ship in the app and is used unmodified. Flag it for the Phase 8 lawyer review. No other non-permissive license is allowed without asking Eddie.

Learned from mistakes (this project)

Newest entries go last.

  • 2026-10-06: I recommended moving the code off the Desktop to protect git from iCloud. That would have taken the code out of Eddie's only backup, and split the project into two places. Rule: the project stays on the Desktop. Keep only build output and big data out of iCloud. iCloud "2" conflict copies are acceptable, because GitHub is the source of truth for code.
  • 2026-10-06: the Lean budget counted one preflop run, but it also funds MTT and Spin postflop libraries. Each of those needs its own preflop charts as input. Eddie approved a budget that was missing those runs. Rule: when pricing any library, count one preflop run for every format and table size it feeds, and show that line separately.
  • 2026-10-06: pnpm 12 silently ignored virtual-store-dir in .npmrc. 989 package files (73 MB) landed in the iCloud-synced web/node_modules before the Phase 0 file-count gate caught it. Rule: after any web install, count the files in web/node_modules. About 11 links is correct; hundreds means packages leaked into iCloud. Delete them right away and fix the setting.
  • 2026-10-07: told Eddie "the app is running at http://localhost:5173". The Claude app had stopped that preview server hours earlier, and the browser pane was hidden, so he saw nothing. Rule: before telling Eddie something is running or viewable, check it live in the same turn (preview_list or a request to it). Anything he should be able to open at any time, from any device, gets published as a private artifact; never point him at localhost.
