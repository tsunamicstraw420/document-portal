GATE 4

Keeping iCloud clean

First try failed, and the gate caught it

The web package tool (pnpm 12) silently ignored the setting that keeps packages out of the project folder. 989 files (73 MB) landed in the iCloud-synced Desktop. I deleted them within minutes. Then I moved the setting to the file pnpm 12 actually reads, and reran the test.

  • After the fix: a full engine and web build adds 0 files to the project folder. Installing packages leaves 11 small links (28 KB) pointing to the work folder.
  • In the work folder, which doesn't sync: 938 package files (73 MB) and the Rust build (34 MB).
  • The lesson is written into the project rules, so future sessions check for it.
ALSO DONE

Setup and fixes

  • Rust 1.99 installed with the official installer. Its fingerprint was checked against rust-lang.org, and your shell settings were left alone.
  • Homebrew stopped. It was compiling tools from source on this Intel Mac, which can take hours. Nothing half-installed was left behind.
  • The solver needed three repairs to build on today's Rust, because it has been frozen since 2023:
    • two file-saving libraries pinned to their 2023 versions;
    • three one-line fixes the compiler itself suggested. They don't change what the solver does, and its built-in correctness checks still pass.
  • GitHub: two private repos, one for the project and one for our offline solver copy. GitHub confirms both are PRIVATE.
  • License check of every library: all permissive. One build-only tool (lightningcss, MPL-2.0) never ships in the app and is flagged for the lawyer review.
