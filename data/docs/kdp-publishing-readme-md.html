kdp-publishing

Three-stage Claude pipeline for Amazon KDP self-publishing: niche research → manuscript draft → title/cover optimization. Wraps the prompts from this article into a runnable CLI.

Setup

pip install -e .
cp .env.example .env
# edit .env, set ANTHROPIC_API_KEY

Usage

Each book is a "project" — a directory under projects/ with a config.yaml and generated artifacts.

# 1. Create a project skeleton
kdp init my-book

# 2. Edit projects/my-book/config.yaml — fill in category, audience, ad_budget

# 3. Stage 1: niche research → projects/my-book/01_niches.md
kdp niche my-book

# 4. Pick a niche, fill in title/problem/length/tone/angle in config.yaml

# 5. Stage 2: manuscript → projects/my-book/manuscript.md + chapters/NN.md
kdp write my-book
# or for a smoke test:
kdp write my-book --length 5000

# 6. Fill in topic/benefit/competitors in config.yaml

# 7. Stage 3: title + cover brief → projects/my-book/titles_and_cover.md
kdp optimize my-book

Add --dry-run to any stage to print the rendered prompt without calling the API.

How stage 2 works

  1. Generates a chapter outline (JSON), saved to outline.json.
  2. Iterates chapters, streaming each. The book brief + outline are sent as the cached system prompt, so chapters 2..N hit the cache instead of re-paying for the prefix.
  3. Per-chapter files written to chapters/NN.md; final concatenation to manuscript.md.

Future hook
