Set up Amazon rendering

About 15 minutes. You make the Amazon account and one access key. I connect the explainer to it and, after your yes in dollars, run one test render.

Before you start
  • Amazon asks for a card and a phone check when you sign up. I can't do that part for you.
  • Never paste the keys from step 7 into the chat. They go only into the file in step 8.
  • Expected cost once running: roughly 10–40¢ per explainer (my estimate until the test).

  1. Create the Amazon account

    Go to aws.amazon.com → Create an AWS Account. Use eddie@solorender.com, account name solorender. Pick the Basic (free) support plan.

  2. Set a spending alert (recommended)

    In the search bar type Budgets → Create budget → Use a template → Monthly cost budget. Amount 5, your email. Amazon then emails you if it ever passes $5 in a month.

  4. Make the role

    IAM → Roles → Create role. Under Use case pick Lambda → Next. In the search box type remotion-lambda-policy, tick it → Next. Role name exactly remotion-lambda-role → Create role.

  5. Make the user

    IAM → Users → Create user. Name remotion-user. Leave Provide user access to the console unticked → Next → Next → Create user.

  7. Make the access key

    Still on remotion-user → Security credentials tab → Create access key. Choose Application running on an AWS compute service, tick the "I understand" box → Next → Create access key. Keep that page open: it shows the Access key and the Secret access key once.

  8. Put the key in the explainer's settings file

    • Open TextEdit → New Document → menu Format → Make Plain Text.
    • Type these two lines, pasting your two keys after the = signs (no spaces):
      REMOTION_AWS_ACCESS_KEY_ID=
      REMOTION_AWS_SECRET_ACCESS_KEY=
    • File → Save. Name it .env (with the dot). Where: Desktop → AI_bots → Magnific_clone → studio → tools → explainer. If TextEdit asks about the dot, choose Use ".". If it offers to add .txt, say no.
    • This file is never uploaded to GitHub (checked: the project ignores .env files).
