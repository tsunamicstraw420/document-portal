vflow.live prompt library — scrape & curation

Full scrape of vflow.live (an "AI video prompts you can watch before you copy" library), categorized, plus a curated set of samples chosen for the SoloRender site.

Scraped 2026-09-18. The site self-reported 8,961 prompts; we captured all 8,961.

How it was scraped

Each vflow prompt page embeds a JSON-LD CreativeWork block containing the prompt text, title, vflow's own one-paragraph analysis, the extracted tags (category · camera · lighting · mood), author, date, source post, and a direct video URL. We pulled every English prompt URL from the site's 65 sitemaps (8,961 — matching the site's own count) and read that block from each page. robots.txt explicitly allows all agents. Non-English pages were skipped: they are translations of vflow's analysis, not different prompts — the prompt text itself is the same original.

Known limitation — vflow truncates long prompts

~41% of prompts (3,676 of 8,961) are stored truncated by vflow itself — long prompts (often multi-shot scripts) are cut mid-sentence on vflow's own pages, so that is all that can be captured. Short and medium prompts are complete. A prompt whose text ends without terminal punctuation is likely truncated at the source. Every one of the 30 curated samples was checked to be complete (they read as finished prompts, not mid-action cuts).

How the 30 samples were chosen

Filters applied before hand-picking (see SOLORENDER_SAMPLES.md):

  • Seedance-weighted — SoloRender ships Seedance models, so these run as-is; Seedance prompts

are directly usable, not just stylistically transferable.

  • Self-contained — no dependency on an uploaded reference image or a linked source clip.
  • Safe to publish — English only, no real brands, celebrities, or trademarked characters.
  • Well-formed — each names a camera move, the single field vflow's data flags as the #1

marker of a working prompt (77.6% of the corpus names one; only 24.9% state an aspect ratio).

  • Complete — no mid-sentence truncation.
  • Diverse — spread across 7 use-case buckets (cinematic, product/commercial, people/UGC,

nature/travel, anime/3D, VFX/transitions, stylized/vintage/stop-motion).

Note on use

These prompts were written by named third-party creators and published on X. SOLORENDER_SAMPLES.md keeps the author credit and source link for each. If SoloRender publishes any of these as on-site sample/starter prompts, keep the attribution or (cleaner) treat them as references and rewrite the on-site copy in SoloRender's own voice.
