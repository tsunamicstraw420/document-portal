Two kinds of upgrade: "just pay" vs. "real work"

Some services you fix by clicking a bigger plan. Others need an actual change (a phone call, a config, or code) — a bigger plan alone won't save you.
Money solves it (just upgrade the plan)
  • Vercel — Pro autoscales your site to thousands of visitors; you only watch the bandwidth meter.
  • Supabase — Pro now, step up to Team as you near 5k concurrent. Must use the connection pooler.
  • Stripe — nothing to do; scales infinitely, cost is just a % of revenue.
  • Claude API — stay on auto-reload; email them to raise the rate limit if a text feature gets hammered.
  • GitHub watchdog — free tier is fine at any scale.
Needs a real change (not just a plan)
  • fal.ai — call them to raise your concurrency cap + get volume pricing before peak load, or users see "generation failed."
  • Render worker — bigger instance to stop the out-of-memory crashes, and run several in parallel (your queue already supports it).
  • Email — wire Resend/Postmark into Supabase or new-signup verification emails silently throttle and fail.
  • Cloudflare R2 — move finished media off Supabase so viewing/downloads stop racking up bandwidth fees.

What actually breaks first

Do these in order. The top three are the ones that fail loudly or silently under real load; the rest just cost more money.
1
fal.ai concurrency limit
Every fal account caps how many generations run at once. At peak you'll hit it and users see "generation failed." Fix: contact fal to raise the cap + negotiate volume pricing before you scale.
2
Render worker: crashes + queue backlog
One worker does one film at a time and runs out of memory on big clips. Fix: bigger instance (2–4 GB) to stop crashes, and run several workers so films don't pile up in a queue.
3
Signup emails silently fail
If verification emails still go through Supabase's built-in sender, new signups won't get them at volume. Fix: plug in Resend or Postmark. Cheap, and prevents a "nobody can sign up" outage.
4
Storage & bandwidth bill balloons
Every clip watched or downloaded is a fee when served from Supabase. Fix: store media in Cloudflare R2 (near-zero fee to serve) behind the CDN.
5
Database connection limit
Thousands of users can exhaust the database's connection slots. Fix: use the Supabase pooler (you likely already do), and move to Team tier near 5k concurrent.
