Executive Summary

This is a complete system guide for building a self-reinforcing knowledge management system combining:

  • Automated capture (no manual friction)
  • Intelligent routing (N8N pipelines)
  • Persistent storage (Obsidian)
  • AI analysis (Claude)

The core insight: most knowledge systems fail because they're designed for input only. This system solves the problem by automating capture, adding AI-powered connection discovery, and creating daily/weekly feedback loops.

Key Problems Identified

The Three Failure Modes of Knowledge Systems:

  1. Capture Friction (>10 seconds per item kills the habit)
  • Problem: Manual tagging, categorizing, summarizing before processing
  • Solution: Automatic capture → zero friction
  1. No Connection Layer (Isolated notes can't talk to each other)
  • Problem: Information sits in silos; no cross-filing system
  • Solution: Claude reads entire vault; surfaces missed connections
  1. No Return Mechanism (Information goes in, never comes back out)
  • Problem: Vault becomes write-only archive
  • Solution: Daily briefs + weekly synthesis force output

Detailed Implementation Steps

STEP 1: Capture Layer Setup

Articles & Highlights:

  • Install Readwise browser extension
  • Highlight as you read (no extra work)
  • Connects to: Kindle, Twitter Bookmarks, Instapaper, Pocket
  • Aggregates everything in one place

Podcasts & Audio:

  • Airr: Shake phone to clip podcast moments (auto-transcribed)
  • Whisper: Run voice notes/meetings through for clean transcription

Quick Captures (Telegram Bot):

  • Build with Claude Code + N8N (30 minutes)
  • Send any message to bot → lands in inbox automatically
  • Use cases: ideas in car, important tweets, random questions

N8N Workflow - Telegram Integration:

Trigger: Telegram message received
├─ Node 1: Extract message, user, timestamp
├─ Node 2: Format as markdown
│  └─ Pattern: # Quick Capture / [message] / Source: Telegram / Date: [date]
└─ Node 3: Write to Obsidian
   └─ File path: /your-vault/inbox/{{date}}-quick-capture.md

STEP 2: Vault Structure (5 Folders Only)

Obsidian Vault/
├── inbox/                    ← Everything lands here first
├── notes/                    ← Processed articles, highlights, research
├── ideas/                    ← Your own thinking, observations, voice notes
├── projects/                 ← Active work (one folder per project)
└── CLAUDE.md                 ← Instructions for Claude (critical)

Key Principle: Simplicity over complexity. Complex structures collapse under their own weight. When in doubt: put it in inbox.

STEP 3: CLAUDE.md Template (The Instruction Layer)

This is the most critical file in the system. Claude reads this first in every session.

# CLAUDE.md - System Instructions

## Who I Am
- **Name:** [Your name]
- **Work:** [What you do — be specific]
- **Focus:** [The one thing you're trying to get better at right now]
- **Goals 2026:** [3 specific outcomes you're working toward]

## Current Projects
- **Active:** [What you're building or working on right now]
- **Stuck on:** [Where you need the most thinking help]
- **Next milestone:** [What done looks like for the current sprint]

## How This Vault Works
- **Inbox:** `/inbox` — unprocessed captures, file here first
- **Notes:** `/notes` — processed articles, highlights, research
- **Ideas:** `/ideas` — my own thinking and observations
- **Projects:** `/projects` — active work folders

## What I Want From You
1. Surface connections I have not seen
2. Challenge my assumptions before agreeing with them
3. When I ask what to focus on — answer from vault context, not generically
4. Flag when something I believe contradicts something I saved earlier

## What I Am Reading and Thinking About
[Update this weekly — current obsessions, active questions, things puzzling you]

Critical: Update this every Monday morning (5 minutes). Stale CLAUDE.md = stale answers.

STEP 4: Daily Brief Automation (N8N)

Triggers: Every weekday at 6:00 AM Runs: Automatically (no manual request needed) Arrives in: /inbox/brief-{{date}}.md

N8N Prompt for Claude:

You are reading my Obsidian knowledge vault. Read everything in /inbox 
from the last 24 hours and everything in /notes from the last 7 days.

Then do three things:

CONNECTIONS
- Find the 3 most interesting connections between recent captures and 
  older notes I probably have not noticed
- Be specific. Quote the relevant passages.

PATTERN
- Identify one pattern across everything I have been reading this week
- What is my brain clearly working on even if I have not said it explicitly?

QUESTION
- Give me one question worth sitting with today based on the pattern 
  you identified
- Not a task. A question.

Write this as clean markdown formatted for Obsidian. 
Save it to /inbox/brief-{{date}}.md

STEP 5: Weekly Synthesis (Deep Dive)

When: Every Monday Time Required: 15 minutes Importance: This is where compounding actually happens

Prompt for Claude:

Read my entire Obsidian vault. Focus on everything added in the last 7 days.

I want four things:

EMERGING THESIS
- What idea am I building toward without having stated it explicitly yet?
- What position is forming in my thinking?

CONTRADICTIONS
- What have I saved recently that contradicts something I believed before?
- Show me both sides from my own notes

KNOWLEDGE GAPS
- Based on what I am reading and thinking about, what am I clearly not reading that I should be?
- What perspective is missing?

ONE ACTION
- What is the single highest-leverage thing I could do or think about this week?

Be direct. Challenge me. Do not summarize what I already know.

Why N8N (And Alternatives)

Why N8N for pipelines?

  • Visual workflow builder (no code needed)
  • Direct Obsidian file write integration
  • Claude API integration
  • Scheduling for automated runs
  • Free tier sufficient for most users

Alternative Tools:

  • Zapier (cloud-based, higher cost, limited local file access)
  • Make (similar to N8N, less Obsidian support)
  • Custom Python script (most flexible, requires coding)
  • IFTTT (simplest, least powerful)

Critical Success Factors

✅ DO:

  1. Keep it simple (5 folders, not 20)
  2. Capture with zero friction (no tagging/summarizing)
  3. Update CLAUDE.md every Monday (5 minutes, critical)
  4. Run weekly synthesis (15 minutes, non-negotiable)
  5. Let automation handle routing (trust the pipeline)

❌ DON'T:

  1. Over-engineer the folder structure
  2. Add manual processing steps to capture
  3. Let CLAUDE.md become stale (updates weekly, not monthly)
  4. Skip weekly synthesis thinking it's "not enough data yet"
  5. Try to tag/categorize as you capture (let N8N handle it)
