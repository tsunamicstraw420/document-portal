Quick Start Implementation Guide

Building Your AI-Powered Obsidian Vault

Total Setup Time: 2-3 hours Monthly Maintenance: 20 minutes (5 min on Monday + 15 min weekly synthesis)

Phase 1: Obsidian Setup (30 minutes)

Step 1.1: Install Obsidian

# macOS
brew install obsidian

# Or download from: https://obsidian.md/download

Step 1.2: Create Vault Folder

mkdir -p ~/obsidian-vault
cd ~/obsidian-vault

# Create the 5 core folders
mkdir -p inbox notes ideas projects

# Create CLAUDE.md in root
touch CLAUDE.md

Step 1.3: Initialize Obsidian

  1. Open Obsidian app
  2. Click "Open folder as vault"
  3. Select your ~/obsidian-vault folder
  4. Confirm to create .obsidian config folder

Step 1.4: Write Your CLAUDE.md

Open CLAUDE.md in Obsidian and paste this template:

# CLAUDE.md - Your Knowledge System

## Who I Am
- **Name:** Eddie Barna
- **Work:** Building AI automation bots for arbitrage & publishing
- **Focus:** Systems that compound over time without manual intervention
- **Goals 2026:** 
  - Master systematic content capture and knowledge synthesis
  - Build 2 production bots (polymarket + KDP)
  - Establish daily compound thinking practice

## Current Projects
- **Active:** Obsidian knowledge vault with Claude integration
- **Stuck on:** Automating content routing without N8N complexity
- **Next milestone:** Daily briefs running automatically by May 15

## How This Vault Works
- **Inbox:** `/inbox` — unprocessed captures, sort later
- **Notes:** `/notes` — articles, highlights, research
- **Ideas:** `/ideas` — my observations and thinking
- **Projects:** `/projects` — active work (polymarket, kdp-publishing, etc)

## What I Want From You (Claude)
1. Find connections across my projects I missed
2. Challenge assumptions when I contradict earlier notes
3. When I ask for priorities - answer based on vault, not generic advice
4. Flag contradictions between what I believe and what I've saved
5. Help identify patterns in what I'm consuming

## What I'm Reading and Thinking About
- Knowledge systems that scale without manual friction
- How Claude can act as a thinking partner across projects
- Patterns in crypto/prediction markets
- Bot automation frameworks

Step 3.2: Build the Daily Brief Automation

In N8N, create new workflow:

  1. Add trigger node:
  • Type: "Schedule"
  • Mode: "Every weekday at 6:00 AM"
  1. Add Claude node:
  • Provider: Anthropic
  • Model: Claude 3.5 Sonnet
  • Temperature: 0.7
  • Paste this prompt:
You are reading my Obsidian knowledge vault as my thinking partner.

Read everything in /inbox from the last 24 hours.
Read everything in /notes from the last 7 days.

Generate a DAILY BRIEF with three sections:

## 🔗 CONNECTIONS
Find 3 most interesting links between recent captures and past notes
I probably haven't noticed. Quote both passages. Be specific.

## 🎯 PATTERN  
One pattern across this week's reading. What is my brain working on?
Be specific. Reference actual notes if possible.

## 💭 QUESTION
One question worth sitting with today, based on the pattern above.
Not a task. A genuine question that challenges my thinking.

Format as clean markdown for Obsidian.
  1. Add Obsidian writer node:
  • Type: "Write Files"
  • Path: /inbox/brief-{{now.format('YYYY-MM-DD')}}.md
  • Content: {{ $node.Claude.json.content }}
  1. Save and test

Step 3.3: Telegram Bot Setup (Optional but Powerful)

Why: Capture ideas from anywhere (phone, car, conversation) in 2 seconds

In N8N:

  1. Create Telegram bot:
   Open: https://t.me/BotFather
   Send: /newbot
   Follow prompts
   Copy: YOUR_BOT_TOKEN
  1. In N8N create new workflow:

Node 1: Telegram Trigger

  • Authentication: Add your bot token
  • Event: "Message"

Node 2: Code block (format markdown)

   const message = $input.all()[0].body.message.text;
   const timestamp = new Date().toISOString().split('T')[0];

   return {
     filename: `inbox/${timestamp}-telegram-capture.md`,
     content: `# Quick Capture
Date: ${timestamp}
Source: Telegram

${message}

---
Needs processing and filing.`
   };

Node 3: Obsidian File Writer

  • Path: {{ $node.Code.json.filename }}
  • Content: {{ $node.Code.json.content }}
  1. In Telegram: Find your bot, send /start
  • Whenever you message it, captures to vault automatically
  • Use for: ideas, tweets to think about, random questions

Step 4.2: Your Weekly Synthesis Session

Every Monday at 9 AM, sit with Claude and ask:

You've been reading my Obsidian vault all week.
Focus on everything I added in the last 7 days.

Give me four things in markdown format:

## 🌱 EMERGING THESIS
What idea am I building toward without stating it explicitly?
What belief is forming that I haven't yet articulated?

## ⚡ CONTRADICTIONS  
What have I saved recently that contradicts what I believed before?
Show me both sides from my actual notes.

## ❓ KNOWLEDGE GAPS
Based on what I'm reading, what am I clearly NOT reading that I should?
What perspective is missing from my vault?

## 💪 ONE ACTION
What's the single highest-leverage thing I could do this week?
Not ten things. One. Based on vault patterns.

Be direct. Challenge me. Don't summarize what I already know.

Save output to: /inbox/synthesis-{{date}}.md

Troubleshooting

Readwise not syncing?

Settings → Integrations → Obsidian
→ Check "Enable sync"
→ Verify folder path: /notes
→ Click "Sync now"

N8N daily brief not running?

Check:
1. Workflow is "Active" (toggle in top right)
2. Trigger time is set to "Every day at 06:00"
3. Claude API key is valid (test connection)
4. File path exists: ~/obsidian-vault/inbox/

CLAUDE.md not being read by Claude?

When asking Claude to read your vault:
1. Explicitly mention "Read my CLAUDE.md first"
2. Share the vault folder path
3. Or paste CLAUDE.md content in the prompt
4. Once you use folder sharing in N8N, it reads automatically
