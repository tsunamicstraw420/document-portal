REBUILD NOTE — July 18 2026

The first staging attempt of these chains failed and was scrapped. All chains were rebuilt clean, plus a 15th (SC-03, Patrick signing) to replace the existing clip that has visible smoke in it. Four rules came out of the debugging, and every chain now follows them:

1. Model must be Nano Banana 2 Flash. Plain Google Nano Banana silently discards reference images, which is why the first SC-20 came back as a stranger's castle. The staging tool resets the model on every edit, so the model pass must always be the last action, then verified.

2. Prompt lives in its own text box wired into the image card's prompt socket — not typed inside the card. This matches the RL-7/8/9 chains that have always worked.

3. Never describe faces in text. Written descriptions of face, hair or eyewear fight the character reference and the model splits the difference — Kara came back wrong and Guillermo lost his glasses. Describe wardrobe, posture and placement only, then say: take faces, hair, skin tone and glasses ENTIRELY from the character references and reproduce them exactly.

4. The style anchor leaks props. It's a photo of a microphone, headphones and a whiskey glass, and the model was dropping those objects into scenes — a recording mic appeared on the therapy-room table. Every prompt now ends with a style-only clause naming those props as excluded.

5. Never write "exhales" in a motion prompt. Kling renders visible breath as smoke. Describe the body instead ("his shoulders drop and he leans back"), and add the clean-air clause.
