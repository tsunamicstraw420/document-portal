EP-02 (Last Resort S3E1) — LEAN SHOT PLAN

Replaces the 84-shot run sheet. Goal: produce an episode in ~a day, not a week.

Strategy (locked with Eddie, July 14 2026)

  • Two tracks: Ruby (host) handled by reuse + lip-sync; Scenes handled by a smaller set of longer clips.
  • Ruby reuse = MAX: a tiny library of reusable base loops (below). Every host cutaway = reuse a loop + lip-sync the line in the free Mac batch. ~40 cutaways → ~6 generations.
  • Scene consolidation = MODERATE: keep the key reenactments unique; reuse establishing/background clips as recurring B-roll under multiple VO lines. Collapse the roll-call/couple run-through into a group clip.
  • Clip length = MIX: Ruby loops 10s; scene clips sized to the beat (5–10s).
  • Workflow = HYBRID: Claude batch-runs the SCENE clips via the connector (spends credits, no turn-taking); Eddie runs the ~6 Ruby loops in-app on unlimited (free).
  • Lip-sync: applied later, free, in one Mac batch (see [[project_ruby_lipsync]] / RUBY_LIPSYNC_CUES.md).
