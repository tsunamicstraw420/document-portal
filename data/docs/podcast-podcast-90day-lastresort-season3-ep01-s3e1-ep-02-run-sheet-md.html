How we run it now

  • Two tracks. RUBY host cutaways = a few reusable loops + lip-sync. SCENES = fewer, longer clips (some reused as B-roll).
  • Turn-taking (this episode): Claude stages one shot at a time in the "Regal Scene Animation Prompts" Space; Eddie runs the node(s) in-app on unlimited (free) and approves; Claude fetches + saves to videos/.
  • Clip length: Kling 2.5 offers 5s or 10s only. Use 10s for wide/reused/host loops, 5s for quick beats.
  • Lip-sync: applied later, free, in one Mac batch (open-source). Line timings tracked in RUBY_LIPSYNC_CUES.md. Ruby clips are generated silent; lip-sync layers on after.
  • Target: ~25 generations/episode (not 84).

Prompt conventions (locked)

  • Be specific, never generic. Describe each named character's build / hair / skin / wardrobe / placement. Generic text ("several couples") makes the model invent extras.
  • Groups: state the exact count ("EXACTLY N people in frame, no one else — no therapists/staff/extras"). For all-12 shots the 12 character refs fill the slots, so put location + style in the text. Glasses ONLY on Jenny and Guillermo.
  • Solo / pair: connect just those character ref(s) + the Style Anchor (v2, 1sqOxO8r4r); describe the location in the text.
  • Motion: direct real motion — pans, push-in/zoom, natural idle life (breathing, glances, breeze). Trust the 6-angle refs to hold likeness; do not smother in "hold still / minimal change" (that freezes the shot). Near-static only for a deliberate locked hold.
  • Verify before video: check the keyframe has the right count and everyone's recognizable; re-roll the keyframe if anyone drifts (free in-app). Kling occasionally outputs a frozen 10s still — just re-run.
  • Speech bubbles (recurring device): comic-style speech bubbles carry key cast quotes (fits the graphic-novel look; keeps character audio silent). Composited in the editor for crisp, correct text — do NOT bake bubbles/text into the generated image. Instead compose the shot leaving clear negative space where the bubble will go, and log the exact quote + placement in SPEECH_BUBBLE_CUES.md. Quotes must be real (from the show/script), not model-invented.
