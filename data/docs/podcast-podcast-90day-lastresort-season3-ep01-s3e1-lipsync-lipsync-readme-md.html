Ruby Lip-Sync — status & workflow

Goal: make each Ruby host cutaway's mouth match her narration, layering lip-sync onto the reusable Ruby loops (videos/RL-*.mp4) using take audio/LastResort_03_01B.m4a. Local, free.

Tool: Easy-Wav2Lip — the one mature free lip-sync tool that runs on Apple-Silicon Macs, takes a video input, and sharpens the mouth (GFPGAN). https://github.com/anothermartz/Easy-Wav2Lip

Already done (by Claude, in-sandbox)

  • ✅ 01B_transcript.txt + 01B_words.json + 01B_segments.json — full word-level transcript of take 01B (reuse the transcript for show notes too).
  • ✅ cues.csv — 25 Ruby cutaways aligned to the episode (clip_id, ruby_loop, start/end, match confidence, line). conf=chk rows are short interjections ("Surprise.", "Deported.", "Moving on.") — positions are right but worth an ear-check.
  • ✅ segments/*.wav — the 25 audio segments already cut (one per cutaway, mono 16k, +0.15s pad).

Remaining: the render (must run on the Mac's hardware)

Lip-sync rendering (Easy-Wav2Lip + face enhancement) can't run on the cloud sandbox — it needs the Mac. Claude will drive this on your Mac; nothing for you to do.

One-time install (handled by 3_render_lipsync.command, or manually):

git clone https://github.com/anothermartz/Easy-Wav2Lip.git ~/Easy-Wav2Lip
cd ~/Easy-Wav2Lip && python3.10 -m venv venv && source venv/bin/activate && pip install -r requirements.txt

Render: 3_render_lipsync.command loops over cues.csv, feeds each ruby_loop + segments/<clip>.wav through Easy-Wav2Lip (quality = Enhanced), and writes videos/lipsynced/<clip>.mp4. Loops are 720p/10s — within the tool's happy range.

Then → DaVinci Resolve

Drop videos/lipsynced/.mp4 (talking Ruby) + the silent scene clips + overlays/.png onto the timeline under Ruby's narration. Free Resolve does the whole edit (imports, 1080p H.264 export, OFX plugins). The Magnific in-timeline panel needs Resolve Studio — not required, since we export clips from Magnific anyway.
