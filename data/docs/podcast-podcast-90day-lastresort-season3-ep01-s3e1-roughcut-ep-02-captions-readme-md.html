EP-02 captions — switchable, Comic style

Use this one: EP-02_v8_CAPTIONS.srt — this is the route that actually works in Resolve. EP-02_v8_CAPTIONS.ass is kept only as a styling reference. Resolve does not carry .ass styling through on import, so use the .srt and style it in the Inspector.

Not burned in. You can restyle, reposition, retime or turn them off at any point without re-rendering a thing.

Install the font first

Resolve needs the Bangers font installed or the captions will fall back to something generic.

overlays/fonts/Bangers-Regular.ttf → double-click it → Install Font. Restart Resolve afterwards.

Load them — the order matters

  1. File → Import → Subtitle, pick EP-02_v8_CAPTIONS.srt. It goes into the Media Pool.
  2. Timeline → Add Track → Add Subtitle Track. ← Do not skip this. Without a subtitle track, step 3 silently does nothing — no error, no warning.
  3. Right-click the subtitle file in the Media Pool → Insert Selected Subtitles to → Timeline Using Timecode.

Style them

Click any caption on the timeline, then use the Caption tab in the Inspector — not the Track tab. The Track tab won't let you change font size.

Set: Bangers, white text, black background box, bottom centre. Changing one caption's style updates the track.

Font size does not transfer between systems or between my mockups and Resolve — the same visual size needs a different number here. Set it by eye against the demo, don't copy a number.

To hide them, click the eye icon on the subtitle track.
