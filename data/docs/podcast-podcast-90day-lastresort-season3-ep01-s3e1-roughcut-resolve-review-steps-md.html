Resolve review loop — do these steps every time I send an updated FCPXML

Repeat this each round: import → watch → mark → export markers → tell me.

1. Import the updated timeline

  1. Open your EP-02 project in DaVinci Resolve (make sure you're on the Edit page — bottom bar).
  2. Top menu: File → Import → Timeline…
  3. Pick the file I sent (e.g. roughcut/EP-02_v4_CLEAN.fcpxml). Click Open, then OK.
  4. A new timeline appears in the Media Pool (top-left) — this is the latest version. Your older ones stay there too, so you can compare.

If clips show red / "Media Offline": right-click any red clip → Relink Media → point to the 90Day_LastResort_Season3 folder → it finds them all. (Video lives in videos/ and kb_clean/, audio in audio/.)

2. Watch it

  1. Press Home to jump to the start. Spacebar plays/pauses.
  2. To see the whole thing at once: Shift+Z (fits the timeline to the window).
  3. Zoom in on the timeline to work: Cmd + / Cmd −.

3. Drop a marker wherever something's wrong

  1. Park the playhead on the spot (nudge frame-by-frame with ←/→).
  2. Click an empty part of the timeline first (so the marker lands on the ruler, not one clip).
  3. Press M to drop a marker → press M again to open the note box.
  4. Type what's wrong, and pick a color:
  • Blue = a picture/timing problem (wrong clip, wrong moment, looping, etc.)
  • Red = an audio problem (stutter, word issue)
  1. Click away to close. Jump between markers later with Shift+↑ / Shift+↓.

(Tip: a pin at the start of the problem plus a short note is enough — you don't need an exact end time.)

4. Export your markers for me

  1. In the Media Pool (top-left), right-click the timeline you're reviewing (the EP-02… item with the timeline icon).
  2. Timelines → Export → Timeline Markers to EDL…
  3. Save it into the roughcut folder, name it EP-02_MARKERS (overwrite the old one — that's fine).

5. Tell me "markers exported"

I read them straight from the file (times + your notes + colors), make the changes, and send you a fresh FCPXML. Back to step 1.

Keyboard quick list: Spacebar = play · Home = start · ←/→ = nudge · M = marker · Shift+↑/↓ = jump markers · Shift+Z = fit · Cmd +/− = zoom
