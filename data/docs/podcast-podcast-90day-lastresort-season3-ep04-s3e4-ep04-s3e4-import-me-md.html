How we work (the loop)

The build script is the master. Always. Resolve is your review room, not your edit bay — you don't hand-cut anything, so nothing you do gets overwritten.

  1. I generate EP04_S3E4_v1.xml from build_timeline.py
  2. You import it and watch it through
  3. You drop markers wherever something's wrong (M on the keyboard, then type the note)
  4. You export the markers: in the Media Pool, right-click the timeline → Timelines → Export → Timeline Markers to EDL… → save into roughcut/
  5. I read the EDL, fix each note at the source — the cue list, the overlay generator, the audio trim — and regenerate the XML
  6. You re-import and we go again

Every fix lands in a script, so it's permanent and repeatable — the same correction never has to be made twice, and it carries forward to the next episode.

Because the timeline is regenerated each round, don't bother nudging clips by hand — it'll be replaced. Just mark it and I'll fix it properly.
