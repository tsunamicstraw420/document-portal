S3E4 — Space block specs (SC-02 … SC-20)

Build each as its own block in the Magnific space. SC-01 already exists and is the reference pattern.

Per block: text prompt node → image-generator → video-generator.

  • image-generator: mode imagen-nano-banana-2-flash, aspectRatio 16:9, resolution 1k; prompt text node → prompt input; library refs + the existing style anchor creation node → reference inputs.
  • video-generator: model kling-25, mode 25, aspectRatio 16:9, duration 10, resolution 720p, withSoundEffects false; image output → first-frame input.
  • Leave everything idle. Never run/generate.

Shared prompt tails (append to keyframe prompts):

  • [FACES] = Take the faces, hair, skin tone and overall look of every person ENTIRELY from the character references and reproduce them exactly — do not restyle, age or slim.
  • [STYLE] = From the style reference take ONLY the rendering style: painterly graphic-novel linework, cel shading, colour palette and cinematic lighting; do not copy any objects or props from it. No text, captions, on-screen graphics, watermarks, or writing of any language anywhere in the frame.
  • [CLEAN] (append to video prompts) = Each person is a single whole figure with no duplication, doubling or ghosting. No other people appear at any point. Clean air with no atmospheric effects: no smoke, no visible breath, no vapour, no haze. No writing, lettering or characters of any language anywhere in the frame.
