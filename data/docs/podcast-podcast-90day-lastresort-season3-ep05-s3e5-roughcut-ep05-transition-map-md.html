EP05 — Transition Map

Built from the locked review timeline (EP05_S3E5_REVIEW.xml — 118 shots, 650.54s, all Ruby lip-sync in place). 117 cuts → 46 transitions, 71 hard cuts. Listed in timeline order; work top to bottom.

Criteria

Default is a hard cut (reality-TV pace). A transition is added only when the cut marks a real change:

  • Story ↔ Ruby (into/out of her booth) — world change → Cross Dissolve ~10f (or a whip / light-leak from your library).
  • Adjacent Ruby angles (two booth shots back-to-back) — hide the jump cut → Cross Dissolve 6–8f.
  • Couple → different couple (new storyline) → Cross Dissolve ~14f.
  • Act breaks (preview→roll call, roll call→body) → Dip to Black ~20f. Body→recap and recap→CTA land on Ruby, so they use a 16f dissolve.
  • Reflective Ruby beats (e.g. "I really wanted it to be real", "I want them to make it") → the dissolve, a few frames longer (14f).
  • Continuous action inside one subject (dance run, a couple's B-roll strung together, the roll-call montage) → hard cut.

Handles — read this first

A centered dissolve borrows frames from past each clip's edit point. Your B-roll/hero shots were rendered exactly to length, so most have no spare frames. The Handles column says what each cut has:

  • both — clean centered dissolve.
  • tail-only / head-only — only one side has media; Resolve places the transition on that side, or shortens it. Fine.
  • none — keep short / dip — no spare either side. Keep it 6–8f, or use Dip to Black/Color (fades to a color, needs no opposing media). Resolve may offer Create Freeze Frames — expected on a review cut.

Ruby clips have a tail handle (239f media, used shorter) but no head (they start at frame 0): into-Ruby cuts are head-only, out-of-Ruby cuts have tail to spare.

Applying in Resolve (quick)

  1. Click the cut point between two clips (it highlights).
  2. Cross Dissolve: Cmd+T applies the standard transition. Make it the default via Effects → Video Transitions → right-click Cross Dissolve → Set as Standard Transition.
  3. Library transitions (whip/light-leak/etc.): Effects → Video Transitions → drag onto the cut.
  4. Duration: select the transition, set frames in the Inspector (frame counts below are at 24fps).
  5. Dip to Black: Effects → Video Transitions → Dip to Color → set color black → drop on the cut.
