The grammar (why each moment gets its pick)

A small, consistent vocabulary reads as intentional; 43 different flashy moves reads as a screensaver. So most cuts share a quiet signature, and the bold moves are saved for the ~4 moments that carry weight:

  • Into Ruby's booth → Basic → Zoom In (12f). Clean punch to the host. Used ~12× — kept subtle on purpose so it never tires.
  • Out of Ruby, back to the story → Basic → Zoom Out (12f). The mirror of the above.
  • Two Ruby angles back-to-back → Glitch → Glitch 1 (8f). A quick glitch sells 'same host, new angle' better than a dissolve and hides the jump cut.
  • One couple → a different couple → Page Style → Move Over Left (16f). A consistent left-push = 'turning the page to the next couple.'
  • Act break into the roll call → 3D Cube → Box Rotate Left (24f). Turns to the six-couple lineup like opening a yearbook.
  • Act break out of the roll call into the story → Split → Split Central In (24f). Opens the show.
  • Into the Kara & Guillermo dance → Basic → Bounce Zoom In (20f). The one celebratory beat — let it bounce.
  • Land the plane (Ruby's last take → recap) → Basic → Zoom Out (20f). Pull back to survey the wreckage.
  • Into the CTA → Glitch → Glitch Zoom In (16f). One spicy punch to open the ask.
  • Everything continuous inside a segment (dance run, a couple's B-roll, the roll-call montage) → hard cut, same as before.

Handles — no longer a worry

These are motion transitions: they cover the cut with movement/blur (or a glitch), so they don't need spare frames on either side the way a cross-dissolve does. That erases the 'none — keep short / dip' warnings from the earlier map. Drop them straight on the cut at the frame counts below.

Install & apply (from the pack's Help)

  1. Install once: double-click Seamless Transitions.drfx (or in Resolve: right-click the Effects panel → Install). Needs Resolve 18+.
  2. Find them: Edit page → Effect Library → Toolbox → Video Transitions → scroll to the Seamless Transitions - … groups.
  3. Apply: drag the named transition onto the cut between the two clips.
  4. Duration: select the transition on the timeline, set the frame count (below) in the Inspector, or drag its edge. 24fps.

Batched apply (fastest — don't drag 43 times)

The trick: make a transition the Standard, then stamp it onto many cuts with one keystroke.

The one move to learn: right-click a transition in the Effect Library → Set as Standard Transition (it gets a red outline). Then click a cut point on the timeline and press ⌘T (Mac) / Ctrl+T (Win) — that stamps the standard onto it. To batch a whole group: ⌘-click several cut points, then one ⌘T hits them all.

Do it in four passes, then the four one-offs. Use the list below to find each group's cuts:

  1. Set Basic → Zoom In as Standard → apply to the 12 "into Ruby" cuts (rows marked Basic → Zoom In). ~12f
  2. Set Basic → Zoom Out as Standard → apply to the 11 "out of Ruby" cuts (skip 9:34 for now). ~12f
  3. Set Glitch → Glitch 1 as Standard → apply to the 11 "adjacent Ruby" cuts (RUBY → RUBY rows). ~8f
  4. Set Page Style → Move Over Left as Standard → apply to the 4 "couple → couple" cuts. ~16f

Then drag the 4 hero moments on individually:

  • 1:03 3D Cube → Box Rotate Left (24f) · 1:13 Split → Split Central In (24f) · 3:14 Basic → Bounce Zoom In (20f) · 9:34 Basic → Zoom Out (20f) · 10:11 Glitch → Glitch Zoom In (16f)

Duration: they drop at Resolve's default (~1s) — fine for a review pass. To dial in my frame counts, set Preferences → Editing → Standard transition duration before each pass, or select a transition and type the number in the Inspector.

Gotcha: if Resolve pops "insufficient media" on a cut, just accept it — these seamless transitions are built to cover the join, so it looks right even with no spare frame.
