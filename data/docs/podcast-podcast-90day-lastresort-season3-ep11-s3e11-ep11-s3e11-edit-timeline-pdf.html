The five things on screen (legend)
    • NEW — a newly generated hero clip (SC-##). The only paid animation.
    • RUBY — reused glam loop + lip-sync. Free.
    • STILL — a held still (a keyframe or a frame pulled from a clip) with an overlay on top. Free.
    • REUSE — a clip or frame shown again, or a callback still. Free.
    • SHARED — logo sting, roll-call portraits, couple grid — library assets. Free.
   Adjacency rule (Eddie, Aug 14): never two / motion clips back-to-back, never two Ken-Burns stills back-to-back. Five
   Ruby cutaways (tagged break) were inserted to split the duplicate still/clip runs. Ruby's face runs long (~3:30) on
   purpose — approved to buy those breaks.
