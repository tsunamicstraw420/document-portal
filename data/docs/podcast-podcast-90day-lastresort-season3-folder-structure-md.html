90 Day: The Last Resort — folder structure (the rule)

Set up July 25 2026. Every episode follows this. No more guessing where anything is.

90Day_LastResort_Season3/
│
├── _READY_TO_UPLOAD/          ⬆️  THE ONLY FOLDER YOU OPEN TO UPLOAD
│     └── EP01_S3E1/               finished episode + shorts + captions + thumbnails + UPLOAD_ME.md
│     └── EP02_S3E2/  (next)
│
├── _SHARED/                   ♻️  reused on every episode — never duplicated
│     ├── still frames/            logo, Ruby sets, style anchors
│     ├── fonts/                   Bangers
│     ├── 90_Day..._Cast/          cast art
│     ├── characters/  locations/  music/  sfx/
│     └── (shared reference docs: animation pipeline, booth/glam angles, lipsync, speech-bubble cues)
│
├── EP01_S3E1/                 🛠️  the WORKSHOP for this episode (raw materials + project files)
│     ├── roughcut/               .fcpxml / .xml timelines, music+sfx stems, caption source
│     ├── lipsync/                word-level timing JSON
│     ├── videos/  kb_v8/         animated scene clips + camera-motion clips  (Resolve's source media)
│     ├── overlays/               this episode's date cards, bubbles, endcard
│     ├── audio/                  narration
│     ├── shorts/  social/  thumbnails/   working outputs
│     ├── shorts_pipeline/        the Shorts tool (make_shorts.py)
│     └── EP-02_*.md              this episode's guides/plans
│
├── EP02_S3E2/  (next episode — same skeleton)
│
└── _TRASH_review/             🗑️  dead files swept here — empty when you're ready

The rule going forward

  1. New episode → make a new EPxx_S3Ey/ folder (copy EP01's skeleton) for the workshop, and a matching _READY_TO_UPLOAD/EPxx_S3Ey/ for deliverables.
  2. Shared stuff stays in _SHARED/ — never copy the font, cast art, logo, etc. into an episode folder.
  3. When an episode is finished, its final files go in _READY_TO_UPLOAD/EPxx/ with an UPLOAD_ME.md. That's the only place you look to publish.
  4. The Shorts tool writes finished Shorts straight into the upload folder; scratch stays in the workshop.

⚠️ One-time thing after this reorg (EP-02)

Your DaVinci Resolve project for EP-02 links to source clips that just moved into EP01_S3E1/. Next time you open it, Resolve may show Media Offline. Fix: right-click in the Media Pool → Relink Clips → point it at EP01_S3E1/ (videos, kb_v8, audio, overlays). You only need to do this if you re-open or re-export EP-02 — the finished file is already exported and safe in _READY_TO_UPLOAD/.
