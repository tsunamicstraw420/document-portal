Verified recipe (already tested end-to-end on the real logo)

Card (one still PNG) — use the Pillow designer, NOT ffmpeg text:

python3 90Day_LastResort_Season3/make_card.py <ep#> "<Episode Title>" CARD.png

Needs pip install pillow; the script resolves the logo and the fonts in 90Day_LastResort_Season3/_SHARED/fonts/ itself. (The render .command already calls this.)

Hold card over narration:

ffmpeg -y -loop 1 -framerate 10 -i CARD.png -i AUDIO.m4a -map 0:v -map 1:a \
-c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p -r 10 -tune stillimage \
-c:a aac -b:a 256k -shortest -movflags +faststart OUT.mp4

Internal trim (E2), build the trimmed audio first, then feed it in as AUDIO:

ffmpeg -y -i SRC.m4a -filter_complex \
"[0:a]atrim=0:108.10,asetpts=N/SR/TB[a0];[0:a]atrim=153.95,asetpts=N/SR/TB[a1];[a0][a1]concat=n=2:v=0:a=1[out]" \
-map "[out]" -c:a aac -b:a 256k TRIMMED.m4a
