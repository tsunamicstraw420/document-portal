Build

  1. youtube_upload.py — uses google-api-python-client, google-auth-oauthlib,

google-auth-httplib2. Installed-app OAuth flow, scopes https://www.googleapis.com/auth/youtube.upload and .../auth/youtube (thumbnails). Client secret at _SHARED/client_secret.json, cached token at _SHARED/yt_token.json (git-ignore BOTH; never print them). For each episode:

  • videos.insert (resumable): snippet(title, description, tags, categoryId="24"

Entertainment, defaultLanguage="en"), status(privacyStatus, selfDeclaredMadeForKids=False).

  • thumbnails.set(videoId, S3E#_thumbnail.png).
  • Print the resulting videoId + watch URL.
  • Read metadata per episode with the reused parser; discover episodes by scanning

_READY_TO_UPLOAD/EP_S3E/ (or a small manifest).

  • Idempotent: keep a state file _SHARED/uploaded_state.json (episode → videoId) and

skip anything already uploaded, so re-runs resume cleanly.

  1. RUN_YOUTUBE_UPLOAD.command — double-click wrapper: ensure deps

(pip install --user google-api-python-client google-auth-oauthlib google-auth-httplib2), run the uploader, print a summary table (episode → videoId → URL → visibility). Unattended.

One-time OAuth setup — walk Eddie through it

In Google Cloud Console, signed in as the podcast account: create/select a project → enable YouTube Data API v3 → configure OAuth consent screen (External; add realityrecapsunfiltered@gmail.com as a test user) → Credentials → Create OAuth client ID → Desktop app → download client_secret.json into _SHARED/. First run opens a browser to authorize; the token caches after that.

Caveats — state these to Eddie up front

  • Unverified-app privacy lock: videos uploaded by an OAuth app that hasn't passed Google's

API audit are forced to Private and can't be flipped Public via the API. Plan: upload as Unlisted (default) — file + all metadata + thumbnail still fully automated — then flip to Public in Studio; OR submit the app for verification to allow API-set Public. Default to Unlisted unless he says otherwise.

  • Quota: each upload ≈ 1600 units; default daily quota = 10,000 → ~6 uploads/day.

7 episodes won't fit in one day — do 6 then the last one next day (the state file makes the resume automatic), or request a quota increase. Handle the quota-exceeded error gracefully.

  • Downstream (CORRECTED 2026-08-14): the original claim here — that flipping a

video Public "fires the existing RSS → Zapier → Facebook/email flow" — was WRONG and caused confusion. There is no such live chain. Flipping Public publishes on YouTube only. The only live Zap is #1 (podcast RSS → Notion tracker). Facebook (Zap #2) and email (MailerLite) are NOT built. RSS comes from Spotify, not YouTube.
