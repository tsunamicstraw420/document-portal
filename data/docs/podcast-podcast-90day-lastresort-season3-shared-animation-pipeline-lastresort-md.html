Credits — how we split the work (IMPORTANT)

Magnific's "Unlimited" only works inside the web app, on unlimited-tier models. The MCP/API always burns credits — every generation Claude runs through the connector deducts from the pool, even on models that are free in the app. Confirmed on Magnific's own pricing + API docs.

So the division of labor:

  • Eddie = the generator. All keyframe images and video clips are generated by Eddie in the Magnific web app on unlimited models → zero credits.
  • Unlimited image models: Nano Banana 2, Seedream 5.0 Lite, Flux.2 Pro (also Grok, Recraft).
  • Unlimited video models: Kling 2.5 720p and MiniMax Hailuo 2.3 Fast (most other video models burn credits).
  • Claude = the director/writer/organizer. Over MCP (free/cheap reads only): transcribe, beat sheets, shot lists, exact prompts, folder organization, character management, captions. Claude does NOT generate media through the connector.

Measured cost (July 2026): a batch of 5 stills + 1 animated clip via MCP = 975 credits (the video is ~90%; stills ~40–60 each; a 5–10s clip ~700–800). So per-shot via MCP ≈ 750–850 credits. At that rate 45,000 credits ≈ ~55 shots ≈ ~7 min of finished animation — under half of ONE 15–20 min episode. Conclusion: episode keyframes + clips MUST be generated by Eddie in-app (unlimited, free); reserve credits for audio (always paid), occasional connector jobs, and days Eddie delegates.

The flow (image-first, Candela method)

  1. Audio → transcript (Whisper, local, free).
  2. Transcript → beat sheet (Claude).
  3. Beat sheet → shot list (Claude) — each row a 5–10s shot: timecode, characters, location, action, camera, keyframe prompt, animation prompt + model.
  4. Keyframe still per shot — Eddie, in-app, unlimited image model, referencing the saved character(s) + graphic-novel style anchor + location.
  5. Animate the still → clip — Eddie, in-app, unlimited video model, 5–10s.
  6. Assemble in the editor under Ruby's audio.
  7. Music + SFX (Artlist) + captions.
  8. Publish (unlisted Wed → public Fri).

Build in a review gate: approve keyframes before animating.

Audio rule

Animated characters have no voices and no character sound. The only audio in an episode is Ruby's narration, plus music and SFX we deliberately add. Animate mouths/gestures to match Ruby's VO beats, not character dialogue.

Keeping the graphic-novel look — Nano Banana + style anchor (NO Custom Style)

Decision: we are NOT training a Custom Style. A trained style is a LoRA that only runs on Flux/Mystic, and we want Nano Banana 2 for images and Kling 2.5 for video (both unlimited → 0 credits). Locking to Flux isn't worth it.

Consistency comes from a style-anchor reference image instead — which is how Nano Banana is built to work:

  • Canonical style anchor = the approved graphic-novel Paola mockup. Saved locally at still frames/STYLE_ANCHOR_graphic_novel.jpg, and it's in your Magnific creations.
  • On every keyframe (Nano Banana 2): add the shot's character(s) + the location + the style anchor image as a reference, and start the prompt with "Graphic-novel semi-real, painterly, cinematic:". Nano Banana matches the anchor's look closely.
  • Video (Kling 2.5): style carries automatically from the keyframe image — nothing extra to add.
No credit cost for any of this: Nano Banana 2 and Kling 2.5 are both unlimited in the web app. (Custom Style / Flux stays off the table unless you ever switch image models.)

Animating a shot in Magnific — step by step (web app, ZERO credits)

Do this per shot on the 84-shot list. Keyframe first, then animate.

A. Make the keyframe still (Image Generator)

  1. Open the AI Image Generator.
  2. Add references: the shot's character(s) (e.g. paola), the style anchor image (still frames/STYLE_ANCHOR_graphic_novel.jpg), and the location (e.g. castle_drawing_room) — or for Ruby cutaways just use a saved Ruby set (ruby_set_booth/cozy/glam/neon).
  3. Paste the shot's keyframe prompt from the shot list (start it with "Graphic-novel semi-real, painterly, cinematic:"). Pick Nano Banana 2 (unlimited → 0 credits). Aspect 16:9. Generate.
  4. Save the winner into 90Day_LastResort_Season3 → still frames.

B. Animate that still (Video Generator)

  1. Open the AI Video Generator (magnific.com/ai/video-generator, or from the AI Suite home). Shortcut: on the keyframe image, click the Video button (bottom-right) → Generate video to open the editor already loaded with that frame.
  2. Click the Image tab (next to the prompt box).
  3. Select your keyframe from Recent creations (or upload it) as the start frame.
  4. Paste the shot's anim prompt (motion + camera) into the prompt field.
  5. Model = Kling 2.5 (720p) — this is UNLIMITED → 0 credits. (MiniMax Hailuo 2.3 Fast is also unlimited.) Do NOT pick Veo, Sora, LTX, etc. — those burn credits.
  6. Aspect 16:9, Duration 5–10s.
  7. Sound effects: OFF. Characters are silent; Ruby's narration + our music/SFX are added later.
  8. Click Generate video.
  9. When it finishes (in Recent creations), move it into 90Day_LastResort_Season3 → Videos. Download if you want a local copy.
  10. Repeat. Generate ALL keyframes first, review them, then animate the approved ones.
Credit guardrail: the ONLY safe-from-credits path is unlimited models in the web app. If a model shows a credit cost next to it, pick a different (unlimited) one.

"RRU Shot Maker" — Space & Flow (optional, faster)

A reusable Space is built: https://www.magnific.com/app/spaces/a2406e4c-bde5-48b7-a150-94f5d1d7cd1c Graph: Style anchor + Location + Character (3 reference images) → Keyframe Image (Nano Banana 2) ← Keyframe-prompt text → image feeds → Shot Video (Kling 2.5, 720p, ~10s) ← Motion-prompt text. Building it cost 0 credits.

Use it per shot (in the WEB APP = free):

  1. Open the Space.
  2. Swap the Character and Location reference images to the shot's people/place (the Style anchor stays fixed — that's what locks the look).
  3. Type the shot's Keyframe prompt and Motion prompt (from the 84-shot list) into the two text nodes.
  4. Click Run on the Keyframe Image node → then Run on the Shot Video node. The clip saves to your creations.

Turn it into a one-click Flow: publish the Space as a Flow with four inputs (character, location, keyframe prompt, motion prompt); keep the style anchor fixed. Then each shot is: fill 4 fields → Run.
