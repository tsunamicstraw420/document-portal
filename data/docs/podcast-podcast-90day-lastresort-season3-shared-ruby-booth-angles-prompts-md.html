Ruby booth — extra camera angles (multi-cam look)

Goal: 2–3 more angles of Ruby in the same booth, so the edit can cut between "cameras" while she talks, like a real podcast. Same room, same outfit, same lighting — only the camera moves.

Generate these in the Magnific app (unlimited/free on your plan). 16:9, 10 seconds, no audio, 720p or better. Save into videos/ with the names below.

Use the saved references — do NOT describe Ruby in text

Text descriptions let the model drift off-model. Connect what we already have:

  • Ruby character — the saved ruby character in your Magnific library.
  • Booth set — the saved ruby_set_booth location in your library.
  • NO Style Anchor. Ruby's look stays as-is; the style anchor is only for the cast/scene shots.

Then the only thing you type is the camera angle + motion (below). Add "no text overlays, no captions, no on-screen graphics."

Easiest route: "Change Camera" off the existing booth frame

Magnific has a Change Camera tool. Take the existing booth keyframe (a frame from RL-1_booth_loop, or the booth set image) and re-angle it — that guarantees the identical set, outfit and lighting, and you're only moving the camera. Then animate each new angle into a 10s clip. This is more reliable than re-generating the scene from scratch.
