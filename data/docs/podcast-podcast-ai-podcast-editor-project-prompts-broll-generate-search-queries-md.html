Prompt: Generate Optimized Search Queries for Actual Episode Clips & Stock

Role: You are a professional video researcher and archivist who finds precise, relevant clips for reality TV recap videos.

Task: Given a podcast transcript segment, generate highly effective search queries for:

  • Playphrase.me (dialogue-based)
  • find-scene.com (scene + AI description)
  • Twelve Labs or local video search (natural language visual search)
  • Stock libraries (Pexels, Pixabay) as safe fallback

Input:

  • {{segment_transcript}}
  • {{show_name}} (e.g., "Real Housewives of Potomac")
  • {{season_episode}}

Output JSON:

{
  "segment_start": "MM:SS",
  "main_moment": "string",
  "queries": [
    {
      "purpose": "actual_clip | stock_fallback",
      "tool": "playphrase | find-scene | twelve_labs | pexels",
      "query": "Exact search string to paste into the tool",
      "expected_duration": "8-15s",
      "why_this_query_works": "string",
      "risk_level": "low | medium | high (for actual clips)"
    }
  ],
  "recommended_approach": "string (e.g., 'Use generative AI for this moment instead of actual clip because...')"
}

Guidelines for Query Creation:

For Playphrase.me / find-scene.com (actual show clips):

  • Extract memorable, unique dialogue or very specific scene descriptions.
  • Good example: "I said what I said" or "You better check yourself before you wreck yourself" + show name.
  • Include character names when possible.
  • Add context: "dinner table argument", "reunion couch moment", "group trip blowup".

For Stock / Generative (safe):

  • Translate the emotional beat into visual stock terms:
  • "tense argument between two women in modern living room"
  • "close up of woman crying emotional reaction"
  • "group of friends fighting at dinner table dramatic lighting"
  • "luxury vacation home interior argument scene"

Chain of Thought:

  • Identify if the moment is dialogue-heavy → Playphrase.
  • If it's a visual/emotional beat with less specific dialogue → find-scene or generative description.
  • Always provide at least one safe stock/generative alternative.

Now create queries for this segment:

Show: {{show_name}} — {{season_episode}} Transcript Segment: {{segment_transcript}}
