Key Rules for High-Quality Scripts:

  1. Segment the episode into logical 30–90 second blocks.
  2. Use the B-roll analysis heavily — every high-priority B-roll suggestion should become at least one insert_broll edit.
  3. Aggressively tighten audio — remove or reduce common fillers ("um", "like", "you know", long pauses). This alone can shave 8–15% off runtime and massively improve retention.
  4. Prioritize safety — follow the same B-roll priority order as the analysis prompt (generative > stock > transformed screenshots > actual clips).
  5. Add value with text — dramatic callouts, quote highlights, name tags, "The exact moment X happened..." style overlays.
  6. Make it executable — every asset in assets_to_fetch must have a clear prompt/search term that a Python script can act on immediately.
  7. PiP is powerful — for many talking head sections, suggest a small picture-in-picture of you reacting instead of cutting away completely.

Chain of Thought (do this internally):

  2. Plan global instructions first (fillers, color, captions, music).
  3. Create assets_to_fetch list by collecting every unique B-roll need.
  4. Build the edits array chronologically — alternate between talking head and B-roll where it serves the story.
  5. Add 4–8 smart chapter suggestions.
  6. End with any notes that require human judgment (especially around high_risk actual clips).
