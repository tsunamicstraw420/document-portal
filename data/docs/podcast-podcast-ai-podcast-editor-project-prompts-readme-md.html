Project: AI-Powered Reality TV Recap Podcast Video Editor Purpose: High-quality, reusable LLM prompts optimized for turning long-form podcast episodes into engaging YouTube videos with contextual B-roll, smart editing, and safe visual choices.

All prompts are designed to work with Claude 3.5/4, Grok, GPT-4o, or local models via LiteLLM. They emphasize:

  • Structured JSON output for easy Python parsing
  • Reality TV-specific visual language
  • Strong copyright safety (prefer stock + generative over actual episode clips)
  • Chain-of-thought reasoning before final output

How to Use These Prompts in Code

Example (Python):

import litellm

def load_prompt(name: str) -> str:
    return Path(f"prompts/{name}").read_text()

prompt = load_prompt("broll/transcript_to_broll_analysis.md")
response = litellm.completion(
    model="claude-3-5-sonnet-20241022",

All prompts use {{variable}} placeholders for easy .format() or f-string injection.

Recommended Workflow (2026 Best Practice)

  1. Riverside/Descript → Export transcript with word-level timestamps + rough audio
  2. safety/copyright_and_fair_use.md → Run first to set guardrails
  3. broll/transcript_to_broll_analysis.md → Get rich B-roll plan (stock + generative + flagged actual clips)
  4. editing/generate_editing_script.md → Produce machine-readable JSON editing script
  5. Python pipeline (MoviePy/FFmpeg) → Execute the script (fetch stock via Pexels API, generate clips via Runway/Kling, composite timeline)
  6. content/ prompts → Generate chapters, titles, descriptions, thumbnails ideas

Reality TV Niche Specifics

These prompts are tuned for:

  • Dramatic confrontations (dinner table arguments, group blow-ups)
  • Emotional reactions (crying, yelling, silent stares, confessionals)
  • Betrayal / alliance shifts
  • "The moment" reveals and shocking edits
  • Luxury / lifestyle B-roll (vacations, parties, shopping)
  • Talking-head / confessional style
  • Heavy use of reaction shots, slow-motion, zooms, text callouts, and Ken Burns effects on stills

Default B-roll priority order (enforced in prompts):

  1. Generative AI video (Runway Gen-3, Kling, Luma, Pika)
  2. High-quality stock footage (Pexels, Pixabay, Coverr — dramatic conversation, emotional reaction, modern home interior)
  3. Your own reaction footage / screenshots with effects
  4. Animated text/graphics / data viz
  5. Actual episode clips — only when heavily transformed + strong fair use justification (rarely recommended for monetized content)
