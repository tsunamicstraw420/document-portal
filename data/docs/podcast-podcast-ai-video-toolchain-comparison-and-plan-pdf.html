This matches the course's core lesson: don't chase a one-click tool — plan first, then use image-to-video (refine a cheap still image, then
animate it). Your two-prompt idea (image prompt, then animation prompt) is that method.

Prompt templates (from the folder, ready to reuse)

Character "source of truth" (build once per character, reuse every shot)

  [Character name] — full-body reference, [age/build], [hair], [signature outfit/colors],
  [distinguishing features]. Neutral expression, even studio lighting, plain background,
  photoreal, 16:9, 2K. This image is the consistency reference for all later shots.



Step 3 — Image prompt (still frame)

  [Subject + who they are] in [environment/setting], [framing: close-up / medium / wide],
  [visual style], [lighting], [time of day], [mood]. Use the character reference for likeness.



Step 4 — Animation prompt (animate the approved still → ~5s)

  Subject action: [exactly what they do — the most important line]
  Camera movement: [e.g., "no camera movement / tripod shot" for a clean pro look, or a slow push-in]
  Emotion / mood / tone: [what the viewer should feel]
  Duration 5s · aspect 16:9 · generate sound: [on/off]


Course guidance baked in: the still already carries subject, style, environment and lighting, so the animation prompt only needs those three lines. Prefer 5s over 10s
(average pro shot is under 5s; saves credits). Keep camera moves simple.
Talking-head Ruby — the specific recipe

  • Lock one Ruby reference image (Nano Banana Pro), simple background — talking-head tools are weak on busy backgrounds.
  • Drive the mouth with Ruby's real narration audio (you already record it) rather than a preset voice — more realistic, and consistent with
    the project's "Ruby records her own voice" decision.
  • Use HeyGen (via PromptEdit) or Artlist Lipsync for segments; for a 30-min episode, generate talking-head only for key stretches (intro,
    transitions, outro) and let B-roll + narration carry the rest — the course's money-saving pattern.
