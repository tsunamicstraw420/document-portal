Import guide — LastResort_03_01

Everything for this episode is in this folder. To build the video:

  1. Import LastResort_03_01_narration.m4a onto the audio track (this is the master timeline).
  2. Import the whole assets/ folder into your media bin — files are named to sort in timeline order.
  3. Drop each asset onto the video track at the timecode below, over Ruby's voice.
  4. Or just open LastResort_03_01_ROUGHCUT.mp4 — it already has everything placed; use this folder to swap/upgrade shots.
