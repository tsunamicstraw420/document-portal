examples/ — Phase 2 end-to-end fixture

A small, real, self-contained fixture that validates the Phase 2 B-roll chain (GROK_MERGE_PLAN.md §12) without needing network, Whisper, or ffmpeg.

Run the regression check

cd vps-pipeline
python3 examples/verify.py      # exit 0 = pass

It runs the real modules — broll_plan.ingest (pydantic validation) then adapter.adapt (anchor→timestamp + actual_clip swap) — over the fixture and compares the output to the golden expected_cue_sheet.csv, plus a few explicit invariants (anchors resolve, times strictly increase, actual_clip gets swapped when clips are disabled, cast_photo points at a real file).

What's in LastResort_03_01/

FileWhat it is
LastResort_03_01.words.jsonREAL faster-whisper output (word-level timestamps) from a 60s slice of Ruby's LastResort_03_01 narration. This is the ground-truth timing.
LastResort_03_01_broll_plan.raw.jsonA representative LLM B-roll plan (as Claude would return it in Cowork). 3 well-spaced cues covering the key paths: artlist_ai (safe generative), actual_clip (to prove the swap fires), and cast_photo (a named couple still).
LastResort_03_01_broll_plan.jsonThe validated/normalized plan (broll_plan.py ingest output).
expected_cue_sheet.csvGolden cue sheet: cues at their real Whisper times (5.9s / 27.8s / 50.7s), actual_clip swapped to artlist_stock, back-compatible columns + Source/Safety Level/Alt.

Regenerating the golden file (if the pipeline output intentionally changes)

cd vps-pipeline
python3 broll_plan.py ingest --plan examples/LastResort_03_01/LastResort_03_01_broll_plan.raw.json \
    --out examples/LastResort_03_01
python3 adapter.py --plan examples/LastResort_03_01/LastResort_03_01_broll_plan.json \
    --words examples/LastResort_03_01/LastResort_03_01.words.json \
    --show "90 Day: The Last Resort" --out examples/LastResort_03_01
cp examples/LastResort_03_01/LastResort_03_01_cue_sheet.csv \
   examples/LastResort_03_01/expected_cue_sheet.csv

Note: the fixture's words.json was made with the tiny Whisper model for size, so a couple of transcript words are slightly off (e.g. "Thornberry"/"Castle with Carol") — that's fine, the anchors are matched verbatim against this same file. Production runs use small/medium.
