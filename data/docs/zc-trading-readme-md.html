ZC Trading — Automated Trading System

Python-based automated trading system implementing Koroush AK's momentum and mean-reversion frameworks, with mandatory human confirmation in early phases.

Status

Phase 1 (Foundation) — in progress. Documentation and project skeleton complete. First indicator (VWAP) and unit tests in progress.

Architecture

Three modules aligned to the "Three Dimensions of Trading Performance":

  1. Strategy — signal generation, S/R detection, regime classification
  2. Risk — position sizing, trade management, daily/weekly loss limits
  3. Psyche — trade logging, journal analytics, behavioral monitoring

All trades require human confirmation through Phase 3. Autonomous execution is deferred to Phase 5.

Roadmap

  • Phase 1 (Weeks 1-3): Indicators, signals, trade logger
  • Phase 2 (Weeks 4-6): Position sizing, stop/TP automation, risk limits
  • Phase 3 (Weeks 7-9): Analytics, weekly reports
  • Phase 4 (Weeks 10-12): TradingView + exchange API integration
  • Phase 5 (Weeks 13+): Auto-execution with human override, deployment to VPS

Success targets (6 months)

Win rate ≥55%, profit factor ≥1.8, max drawdown <15%, monthly return 5-10%.
